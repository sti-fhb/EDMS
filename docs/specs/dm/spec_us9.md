# User Story 9 — 個人專區（UCDM09 / DM07）

> 返回總檔：[spec.md](spec.md) | 模組：文件管理（DM）

> **平台對齊（DP）**：**「個人資料維護」（姓名 / 帳號 Email / 密碼變更）是另一個功能、由平台模組 DP 提供（UCDP004），入口在頁面右上角使用者選單、操作共用 `DP_USER`——不屬本 US、DM 不實作。** 本 US「**個人專區**」為 **DM 左側功能列之個人工作區**，內含三塊 **DM 業務**：**我的文件動態 + 草稿匣 + 撤回送審**（皆編輯者 / 審核者作業）。**入口僅對具編輯者或審核者角色之使用者顯示**（純閱覽者 / 純管理者左側不顯示個人專區）。

## User Story

編輯者 / 審核者於左側「個人專區」集中管理個人文件作業：**草稿匣**（未送審 / 被退回 / 已撤回三類草稿之續編與刪除）、**撤回送審**（把卡住的送審項目撤回重編改選審核者再送）、**我的文件動態**（近 30 天個人相關事件之撰寫者 / 審核者視角）。個人資料（姓名 / Email / 密碼）之維護為另一功能、於右上使用者選單由平台 DP 提供。

**Priority**: P2 — 草稿與撤回送審為編輯者處理卡關送審之重要手段、我的文件動態為個人事件彙整，但非首發必要（文件核心 US3~US6 先行）。

**Independent Test**: 具編輯者角色者於左側進入個人專區，於草稿匣續編 / 刪除草稿、對卡住之送審項目撤回（回草稿 / 已發布）並改選新審核者再送；編輯者 / 審核者於我的文件動態見近 30 天事件；純閱覽者 / 純管理者左側**看不到**個人專區入口。

### Acceptance Scenarios

1. **Given** 具編輯者或審核者角色之使用者，**When** 檢視左側 DM 功能列，**Then** 顯示「個人專區」入口；純閱覽者 / 純管理者（未兼編輯者 / 審核者）**MUST NOT** 見到此入口
2. **Given** 編輯者進入個人專區，**When** 載入，**Then** 顯示「草稿匣」，列未送審草稿 / 被退回待修改 / 已撤回送審三類
3. **Given** 編輯者於草稿匣，**When** 按「繼續編輯 / 修改」進 [spec_us5.md](spec_us5.md)；按「刪除」，**Then** 跳確認後刪除（不可復原、僅影響草稿不影響已發布版本）（DM-MSG-DM07-004）
4. **Given** 編輯者對卡住之送審項目按「撤回送審」，**When** 確認，**Then** 新增 / 新版本送審 → 回草稿；廢止申請 → 回已發布；以系統內訊息通知原指派審核者；可重新編輯並改選新審核者再送（DM-MSG-DM07-005）
5. **Given** 編輯者 / 審核者進入「我的文件動態」，**When** 載入，**Then** 依角色 tab 呈現近 30 天事件（撰寫者視角：送審中 / 核准發布 / 退回 / 廢止待簽核 / 已廢止 / 已撤回；審核者視角：待處理 / 催辦中 / 已被撰寫者撤回 / 已處理歷史）；同時具兩角色者兩 tab 皆顯示

## Functional Requirements

- **FR-001**: 系統 MUST 於「個人專區」提供**草稿匣**（編輯者），列出未送審草稿 / 被退回待修改 / 已撤回送審三類；提供「繼續編輯 / 修改」（→ [spec_us5.md](spec_us5.md)）與「刪除」（須確認、不可復原、僅影響草稿不影響已發布版本）。三類皆為 `DM_DOC_VERSION` DRAFT，**依該版本之 `DM_REVIEW` 歷史判定分類**：未送審＝無對應送審紀錄；被退回＝最近一次送審為 `REJECTED`；已撤回＝最近一次送審為 `WITHDRAWN`
- **FR-002**: 系統 MUST 提供**撤回送審**（編輯者）：將送審中項目回復狀態（新增 / 新版本 → 草稿；廢止 → 已發布），以**系統內訊息**通知原指派審核者（範本 `SUBMIT_WITHDRAWN`、管道 MSG_ONLY、不發 Email），並允許重新編輯與改選新審核者再送；原送審週期之指定審核者紀錄保留不被改寫（撤回以 `DM_REVIEW` 狀態 `WITHDRAWN` 記錄）
- **FR-003**: 系統 MUST 提供**我的文件動態**，依角色 tab 呈現近 30 天事件（撰寫者視角 / 審核者視角）；同時具兩角色者兩 tab 皆顯示
- **FR-004**: 個人專區**入口可見性** MUST 依角色：僅對具**編輯者或審核者**角色者顯示；純閱覽者 / 純管理者（未兼編輯者 / 審核者）MUST NOT 見到個人專區入口（其個人事務僅有右上之平台 DP 個人資料維護）

> **個人資料維護不在本 US**：姓名 / Email 延遲生效切換 / 密碼變更（驗舊密碼）由平台模組 DP 提供（UCDP004），入口於右上使用者選單，操作共用 `DP_USER`（ET 端同步生效）；忘記密碼走登入頁（[spec_us2.md](spec_us2.md)）。此三項之行為與帳號實體以平台 DP 為準。
