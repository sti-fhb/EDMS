# User Story 2 — 登入 / 註冊 / 忘記密碼（UCDM01）

> 返回總檔：[spec.md](spec.md) | 模組：文件管理（DM）

> **平台對齊（DP）**：**登入 / 註冊 / 忘記密碼、帳密 / 個資維護皆由平台模組 DP 統一提供（UCDP001–004、單一登入、簡單 JWT、共用 `DP_USER`），DM 完全不實作、不自設任何登入 / 註冊 / 忘記密碼畫面。** 使用者一次登入即可存取 ET / DM 兩系統。本 US 於 DM 端唯一之實作為**存取閘**：使用者經 DP 登入後進入 DM 時，DM 檢查其是否具**任一 DM 角色**，無則拒絕進入並提示洽管理者開通（DM-MSG-LOGIN-007）。原「首次進入 DM 自動授予閱覽者」**已作廢**（2026-07-08 平台釐清：新帳號預設僅 **ET 學員**，DM 全部四角色〔含閱覽者〕一律由管理者於平台 DP 後台權限管理開通）。

## User Story

使用者以帳號（Email）+ 密碼經平台 DP 登入後進入 DM；DM 依其 DM 角色決定可否進入——具任一 DM 角色者導向 DM00 系統儀表板，無任何 DM 角色者被拒絕並提示洽管理者開通（不自動授予）。DM 與 ET 共用同一 `DP_USER`，註冊一次即可登入兩系統。

**Priority**: P1 — 存取閘為所有 DM 作業之進入基礎；無此判定則無法正確控管 DM 存取。

**Independent Test**: 以具 DM 角色之帳號登入 → 導向 DM00 儀表板；以無任何 DM 角色之帳號登入 → 被拒進入 DM 並顯示「尚未開通文件管理權限，請洽管理者」；直接以 URL 存取 DM 功能亦被後端擋下。

### Acceptance Scenarios

1. **Given** 使用者已於平台 DP 登入且具**任一 DM 角色**，**When** 進入 DM，**Then** 導向 DM00 系統儀表板，並依角色顯示對應功能
2. **Given** 使用者已於平台 DP 登入但**無任何 DM 角色**，**When** 進入 DM（含直接以 URL 存取 DM 功能），**Then** DM 後端拒絕並提示洽管理者開通（DM-MSG-LOGIN-007），MUST NOT 自動授予任何 DM 角色
3. **Given** 使用者尚無帳號 / 忘記密碼 / 欲改帳密，**When** 於登入頁註冊 / 申請重設 / 於右上使用者選單改帳密，**Then** 由平台模組 DP 處理（UCDP001–004），DM 不介入；註冊後之帳號預設僅具 ET 學員角色、DM 角色需由管理者另行開通

## Functional Requirements

- **FR-001**: 登入成功後，DM MUST 取得該使用者之 **DM 角色清單**（`DM_USER_ROLE`），並據此判定存取：具任一 DM 角色者放行、導向 DM00；**無任何 DM 角色者 MUST 拒絕進入 DM**（含直接呼叫 API），提示洽管理者開通（DM-MSG-LOGIN-007）；MUST NOT 自動授予（2026-07-08 作廢「自動授予閱覽者」，DM 角色一律由管理者於平台 DP 後台權限管理開通）
- **FR-002**: 登入 / 註冊 / 忘記密碼之認證流程、帳密 / 姓名 / Email 之維護，MUST 由平台模組 DP 提供（UCDP001–004、簡單 JWT、共用 `DP_USER`）；DM MUST NOT 自建認證或帳號維護畫面。因與 ET 共用 `DP_USER`，帳密 / 姓名變更於兩系統同步生效

## 系統訊息

| 訊息代碼 | 類型 | 訊息內容 | 觸發 / 對應 FR |
|---------|------|---------|---------------|
| DM-MSG-LOGIN-007 | 提示 | 尚未開通文件管理權限，請洽管理者 | FR-001 無任何 DM 角色 |

> 登入失敗（帳號不存在 / 未驗證 / 密碼錯誤）、註冊、忘記密碼等訊息由平台模組 DP 呈現（見平台 [specs/dp/spec.md](../dp/spec.md)），非 DM 訊息。

## 前置依賴

- 認證能力（登入 / 註冊 / 忘記密碼）與共用使用者主檔 `DP_USER` 由平台模組 DP 提供（UCDP001–004）；第一位管理者由 IT 經 DB 寫入（見 [spec_us1.md](spec_us1.md)）
- DM 角色判定資料 `DM_USER_ROLE`（角色由管理者於平台 DP 後台權限管理開通，指派 / 判定屬 DM，見 [spec_us1.md](spec_us1.md)）
- 登入成功導向之 DM00 儀表板見 [spec_us7.md](spec_us7.md)
