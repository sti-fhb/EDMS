# User Story 7 — 系統儀表板（入口頁 DM 文件概況）（UCDM02）

> 返回總檔：[spec.md](spec.md) | 模組：文件管理（DM）

## User Story

具 DM 角色之使用者登入後落在平台**中性歡迎頁（入口頁）**，於頁面依權限疊加之「DM 文件概況」區塊快速掌握各類型文件總數與近期更新動態：上方呈現 4 類內建分類之已發布文件總數，下方列出近 30 天內已發布文件之公告，點擊可進入詳細頁。

> **設計依據（導覽重構 #89，DP [spec_us1.md](../dp/spec_us1.md) FR-DP-US1-07 / D1·D2）**：EDMS 為多模組平台，登入後主頁為**中性歡迎頁**（問候 + 系統定位 + 版本，不綁任何模組權限、永遠存在）；各模組儀表板**不另設獨立落地頁**，其內容由各模組定義、以**依權限疊加之 widget** 呈現於中性歡迎頁。故本 US 交付＝**DM 文件概況 widget**（具任一 DM 角色者顯示；無 DM 角色者不顯示，最小知悉），**非**獨立 DM00 落地頁、無自動導向、無「home / 系統名稱返回 DM00」機制。

**Priority**: P2 — 提升掌握度與導覽便利性，但非核心作業；缺此區塊仍可由側欄「文件庫」完成檢索與閱讀。

**Independent Test**: 具 DM 角色之使用者登入後於中性歡迎頁見「DM 文件概況」區塊——四類統計卡與總計（僅計已發布目前版本、套可見性）、近 30 天發布公告（新增 / 新版本）；點公告進詳細頁、點「查看全部文件」進文件庫；近 30 天無發布時該區塊顯示空狀態；**無任何 DM 角色之使用者不顯示此區塊**。

### Acceptance Scenarios

1. **Given** 具任一 DM 角色之使用者登入，**When** 中性歡迎頁載入，**Then** 於頁面依權限顯示「DM 文件概況」區塊（統計 + 公告）；**無任何 DM 角色者 MUST NOT 顯示此區塊**（最小知悉，對齊 #89）
2. **Given** DM 文件概況區塊渲染，**When** 呈現統計，**Then** 顯示 4 張統計卡（SOP / 系統操作手冊 / 訓練教材 / 其他）之已發布目前版本數量與總計
3. **Given** 統計卡，**When** 計數，**Then** 僅計入「已發布」之目前版本（**含廢止待簽核＝仍在架**；排除送審中 / 草稿 / 已被取代之舊版本 / 已廢止），並**套標籤式可見性**（閱覽者僅計其可見範圍，比照 [spec_us3.md](spec_us3.md) FR-008）；卡片為純資訊、不可點擊
4. **Given** DM 文件概況區塊渲染，**When** 呈現公告，**Then** 列出近 30 天內已發布文件（含新增首版與新版本兩類事件），每筆顯示文件名 + 類型 badge（新增 / 新版本）+ 摘要 + 發布日期 + 撰寫者 + 分類，並**套可見性**（閱覽者僅見其可見範圍）
5. **Given** 使用者點任一公告，**When** 點擊，**Then** 進入該文件詳細頁（[spec_us4.md](spec_us4.md)）；點「查看全部文件」進文件庫（[spec_us3.md](spec_us3.md)）
6. **Given** 近 30 天無任何發布事件，**When** 渲染公告區，**Then** 顯示「近期無新發布文件」（DM-MSG-DM00-001）

## Functional Requirements

- **FR-001**: DM 文件概況 MUST 呈現於平台**中性歡迎頁**（入口頁）之依權限疊加區塊，**不另設獨立落地頁 / 側欄入口 / 自動導向**（導覽重構 #89，DP spec_us1 FR-DP-US1-07）；**具任一 DM 角色者顯示、無任何 DM 角色者 MUST NOT 顯示**（最小知悉）。widget 之呈現條件由 DP 前端依模組回呼（`has_any_role`）決定、內容由 DM 定義
- **FR-002**: 「各類型文件總數」MUST 對應 4 內建分類，顯示各分類已發布目前版本數量與總計；計數 MUST 僅計入已發布目前版本（**含廢止待簽核之在架文件**；排除送審中 / 草稿 / 舊版 / 已廢止），並 MUST 套標籤式可見性（閱覽者僅計其可見範圍，比照 spec_us3 FR-008）；卡片為純資訊、不可點擊
- **FR-003**: 「最新更新公告」MUST 列出近 30 天內已發布文件（含新增首版與新版本兩類事件），每筆含 文件名 / 類型 badge / 摘要 / 發布日期 / 撰寫者 / 分類，並 MUST 套可見性
- **FR-004**: 點公告 MUST 進入 [spec_us4.md](spec_us4.md) 詳細頁；點「查看全部文件」MUST 進入 [spec_us3.md](spec_us3.md) 文件庫；近 30 天無事件時顯示空狀態提示
