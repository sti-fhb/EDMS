# User Story 3 — UCET002 課程建立與編輯（ET05）

> **2026-10-06 #538**：「受訓單位標籤」改為「**受訓對象**」（單位 + 職位配對），見 [spec.md](spec.md) §受訓對象規則。下列情境中之「標籤」皆指配對；與改訂後之 FR 衝突時以 FR 為準。

> 對應 UC：UCET002 ｜ 功能選項：ET05（新增／編輯課程）｜ Priority：P1 ｜ Wireframe：[課程建立／編輯畫面](../../wireframes/et/index.html) ｜ 返回總檔：[spec.md](spec.md)

教師於 ET01 課程列表點「新增課程」進入新增模式，或點既有課程卡片進入編輯模式。本作業為 ET 最核心之教師端作業，涵蓋課程基本資料（課程名稱、**受訓單位標籤多選**、**課程起訖時間（閱課期間）**、課程描述、**是否需線下核可**）、章節編排（拖拉式調整章節 / 教材 / 測驗順序）、教材管理（影片本地上傳 / DM 文件引用 / 說明文字三類媒材自由組合）、測驗建立與題庫管理（單選 / 多選題、配分總和 100、題目順序系統內建洗牌、軟刪除）、**課後回饋問卷建立（0～1 份 / 課程，選配）**、儲存草稿與發布（發布時觸發**標籤自動邀請＋寄通知信**）、關閉與再開課（**可逆**，屬 [spec_us11.md](spec_us11.md) US11）、邀請學員（屬 [spec_us8.md](spec_us8.md) US8）等子功能。多裝置同時編輯採樂觀鎖（含問卷本體）。

**Priority**: P1

**Why this priority**: 教師核心作業，學員端所有學習活動之資料來源；無課程建立即無學員學習與測驗。

**Independent Test**: 教師完整建立一門課程（含至少 1 章節 + 1 教材 + 1 測驗、至少 1 個受訓單位標籤、課程起訖時間）並發布，標籤對應學員自動加入課程並收到通知信，於起始時間後可於 ET06 開始學習；亦可於 ET03 透過邀請碼加入。

**Acceptance Scenarios**:

### 基本資料

1. **Given** 教師於 ET01 點「新增課程」，**When** 進入 ET05 新增模式，**Then** 系統顯示課程名稱（必填）、受訓單位標籤（**多選**，自 `ET_TAG` 啟用中標籤選取；發布時至少 1 個）、課程起訖時間（閱課期間，起、訖兩個時間；發布時必填）、課程描述（選填，至多 500 字）、**是否需線下核可（`REQUIRE_APPROVAL`，開關，預設否）**等欄位，皆為空白 / 預設值
1a. **Given** 教師勾選「是否需線下核可」，**When** 儲存並發布，**Then** 該課程於學員線上完課後須經教師 / 管理者線下核可（→ [spec_us16.md](spec_us16.md) US16）；未勾選則無核可流程；此設定**不影響完課判定**，草稿 / 已發布 / 已關閉狀態皆可調整
2. **Given** 教師僅填寫課程名稱後點「儲存草稿」（標籤與起訖時間留空），**When** 系統儲存，**Then** 寫入 ET_COURSE 狀態為「草稿」、擁有者為當前使用者；**受訓單位標籤與起訖時間於草稿狀態允許留空**（發布時才檢核）
3. **Given** 課程為「草稿」狀態，**When** 教師增刪受訓單位標籤，**Then** 系統允許**自由增刪**
4. **Given** 課程為「已發布」狀態，**When** 教師**新增**一個受訓單位標籤並儲存，**Then** 系統對該標籤對應且尚未加入之學員執行**補邀請＋每人寄通知信**（統一範本）；既有學員不受影響
5. **Given** 課程為「已發布」狀態，**When** 教師嘗試**移除**既有標籤，**Then** 系統阻擋（移除鈕不顯示）；已發布課程之標籤僅可新增、不可移除
6. **Given** 某標籤已被管理者停用，**When** 教師開啟標籤多選清單，**Then** 停用標籤不出現於可選清單；課程既有已掛之停用標籤保留、不受影響

### 章節編排

7. **Given** 教師於章節編排區點「新增章節」，**When** 系統建立空章節並追加至最末，**Then** 可立即拖拉調整順序
8. **Given** 教師對既有章節點「刪除」，**When** 跳 confirm modal 確認，**Then** 章節本體軟刪除（DELETED=1）；學員於該章節之學習紀錄與測驗成績**連帶軟刪除**（不再顯示、不計入完課率，但 DB 保留可回復）；後續章節順序自動往前遞補

### 教材管理

9. **Given** 教師於章節中點「新增項目 → 教材」，**When** 開啟教材編輯視窗，**Then** 可組合三類媒材：影片（本地上傳 mp4 / webm，單檔 ≤ `DP_PARAM.ET_VIDEO_MAX_SIZE_MB`，預設 500 MB）、文件（從 DM「訓練教材」分類下拉選取）、說明文字（WYSIWYG）
10. **Given** 教師選取一份 DM 文件加入教材，**When** DM 端發布新版本，**Then** 學員端下次開啟章節即取得最新版（無快取延遲）
11. **Given** 教材引用之 DM 文件已被廢止，**When** 教師進入 ET05 編輯，**Then** 該引用旁顯示「此文件已廢止」警告標籤；發布時系統阻擋並提示「請先移除廢止文件之引用後方可發布」
12. **Given** 教師欲移除廢止文件引用，**When** 開啟該教材編輯視窗，**Then** 須**逐筆刪除**該引用（系統不提供批次移除）

### 測驗建立

13. **Given** 教師於章節中點「新增項目 → 測驗」，**When** 開啟測驗編輯視窗，**Then** 可設定測驗名稱（必填）、測驗說明（選填，純文字，顯示於學員作答開始前）、及格分數（必填，0–100，預設 80）、作答時間限制（選填，分鐘；**空白 = 不限時**、≥ 1 = 限時分鐘）、重考次數上限（必填，0–999，預設 3，0 = 不允許重考）
14. **Given** 教師建立多選題並僅勾選錯誤選項（無正確選項），**When** 點儲存，**Then** 系統阻擋並提示「請至少指定 1 個正確選項」
15. **Given** 同一測驗下各題配分總和 ≠ 100，**When** 教師欲發布課程，**Then** 系統阻擋並提示「配分總和須等於 100」
16. **Given** 教師對既有題目點「刪除」，**When** 跳 confirm modal 確認，**Then** 題目本體軟刪除；學員於該題之作答紀錄與得分**連帶軟刪除**（不再顯示、不計分，但 DB 保留可回復）

### 課後問卷建立（2026-07-02 新增）

17. **Given** 課程尚無課後問卷，**When** 教師於 ET05 點「新增課後問卷」，**Then** 系統建立問卷（掛課程層級，不掛章節）；可設定問卷名稱並新增題目
18. **Given** 教師於問卷中新增題目，**When** 編輯題目，**Then** 每題可選**單選**或**問答**（2026-08-28 變更，原為一律單選）；單選題之選項由教師自行新增 / 編輯 / 刪除（如：滿意 / 普通 / 不滿意）且每題至少 2 個選項（無上限）；**問答題僅填題幹、不得有選項**，學員以文字作答（至多 150 字）
19. **Given** 某**單選題**選項不足 2 個，**When** 教師點儲存，**Then** 系統阻擋並提示「每題至少需 2 個選項」；**問答題若帶有選項**，系統阻擋並提示「問答題不可設定選項」（**明確擋下而非靜默忽略**——教師由單選改為問答時，選項若被無聲丟棄，他會以為仍然存在）
20. **Given** 問卷尚無任何學員填答，**When** 教師修改題目或選項，**Then** 系統允許**自由編修**（新增 / 編輯 / 刪除）
21. **Given** 問卷已有任何學員填答，**When** 教師嘗試修改題目或選項，**Then** 系統阻擋並提示「已有學員填答，題目與選項不可修改」；此時教師僅可**停用問卷**（題目凍結規則）
22. **Given** 課程已存在 1 份問卷，**When** 教師嘗試再新增問卷，**Then** 系統阻擋（一門課程 0～1 份）
23. **Given** 課程未建立問卷，**When** 教師點發布，**Then** 系統**不因此阻擋**（問卷為選配；填寫問卷不是完課條件、不計入學習進度 %）

### 儲存與發布

24. **Given** 教師完成編輯點「發布」，**When** 系統檢核「至少 1 章節 + 1 教材」＋「**至少 1 個受訓單位標籤**」＋「**課程起訖時間已填**」＋「各測驗配分總和 = 100」＋「無引用之廢止 DM 文件」，**Then** 通過後狀態變更為「已發布」、寫入首次發布時間戳、系統自動產生 8 碼邀請碼
25. **Given** 發布檢核通過完成發布，**When** 系統處理，**Then** 依課程標籤**自動邀請**對應人員（限具「學員」角色者；多標籤取聯集、去重；「全體」= 全部具學員角色者）並**每人寄一封通知信**（統一範本，教師不可編輯主旨內文）
26. **Given** 教師發布時未掛任何標籤或未填起訖時間，**When** 點發布，**Then** 系統阻擋並提示具體缺漏項目
27. **Given** 課程已發布但尚未到起始時間（`OPEN_START_AT`），**When** 學員開啟 ET03 我的課程，**Then** 課程**不顯示、無法進入學習**（起始時間前對學員不可見）；教師端正常可見可編輯
28. **Given** 已發布課程教師繼續編輯（含基本資料、受訓對象、章節與其內容），**When** 他做出任何修改，**Then** 修改進入**編輯暫存區**、學員看到的仍是上一次生效的版本；教師自己看得到自己的編輯
28a. **Given** 教師按底部的「更新」，**When** 系統重跑發布檢核且通過，**Then** 本輪全部編輯**一併對學員生效**，並導回 ET01 課程列表
28b. **Given** 教師按「更新」但檢核未通過，**When** 系統處理，**Then** 以視窗列出缺漏，**學員可見內容一行都不變**，教師停留於編輯頁可就地補齊後再按一次
28c. **Given** 教師有尚未生效的編輯，**When** 他未按「更新」即離開編輯頁（含關閉分頁），**Then** 本輪編輯**全部放棄**；站內導航時先跳確認視窗，關閉分頁所留下的殘留於下次進入編輯頁時丟棄
    > 28～28c 為 #631（內容進暫存）與 #720（基本資料與受訓對象一併進暫存、動作列改版）之後的行為，詳見 FR-ET-US3-14 / FR-ET-US3-17。
    > **原情境 28（#631 之前）**：已發布課程教師繼續編輯 → 點儲存 → **變更即時生效**，無需重新發布。⚠️ 該敘述自 #631 合併起即不成立，2026-10-19 由 #720 一併補正。
29. **Given** 已發布課程教師新增章節，**When** 他按「更新」使之生效，**Then** 系統自動寄信通知所有已加入學員（包含已完課學員）；已完課學員之完課狀態自動回退為「進行中」（學員已填之課後問卷不因回退而失效或重填）

### 樂觀鎖

30. **Given** 教師於 A 裝置開啟編輯（記錄 VERSION=5），同時於 B 裝置編輯同一課程並儲存（VERSION → 6），**When** A 裝置點儲存，**Then** 系統拒絕並提示「內容已被其他裝置變更，請重新整理後再儲存」
31. **Given** A、B 裝置編輯**同一課程之不同章節**，**When** 各自儲存，**Then** 互不衝突（樂觀鎖檢核粒度為單一實體；課程 / 章節 / 教材 / 測驗 / 題目 / **問卷本體**皆各自維護 VERSION）

## Functional Requirements

- **FR-ET-US3-01**（2026-10-06 由 #538 改訂）: 系統 MUST 提供課程基本資料欄位——課程名稱（必填）、**受訓對象**（「單位 + 職位」配對清單，可多組；單位與職位皆自 ET_TAG 啟用中標籤選取）、課程起訖時間（閱課期間，起、訖兩個時間）、課程描述（選填，至多 500 字）、是否需線下核可（`REQUIRE_APPROVAL`，布林，預設 false）；草稿狀態允許受訓對象與起訖時間留空，發布時始檢核；新增課程時預帶一列空白配對；儲存草稿時寫入 ET_COURSE 狀態「草稿」、擁有者為當前使用者。每組配對兩欄皆必填，不完整或重複之配對 MUST 於送出前擋下。
    > **改訂理由**：受訓對象改為「單位 + 職位」配對，見 [spec.md](spec.md) §受訓對象規則（#538）。
    > **原條文**：系統 MUST 提供課程基本資料欄位——課程名稱（必填）、受訓單位標籤（多選，自 ET_TAG 啟用中標籤選取）、課程起訖時間（閱課期間，起、訖兩個時間）、課程描述（選填，至多 500 字）、是否需線下核可（`REQUIRE_APPROVAL`，布林，預設 false）；草稿狀態允許受訓單位標籤與起訖時間留空，發布時始檢核；儲存草稿時寫入 ET_COURSE 狀態「草稿」、擁有者為當前使用者。
- **FR-ET-US3-16**: 系統 MUST 提供「是否需線下核可」（`REQUIRE_APPROVAL`）開關且允許於任一狀態調整；設為 true 時該課程於學員線上完課後啟用線下核可流程（→ [spec_us16.md](spec_us16.md) US16），設為 false 時無核可流程；此設定 MUST NOT 影響完課判定 / 完課率 / 課後問卷開放 / 週報統計。
- **FR-ET-US3-02**（2026-10-06 由 #538 改訂；2026-10-12 由 #586 再訂）: 系統 MUST 於「草稿」**與「已關閉」**課程允許自由增刪受訓對象配對；**僅於**「已發布」課程限制為只允許新增配對（既有配對不可移除、不可修改，移除鈕不顯示；同職位換單位視為移除），新增配對時**僅對該配對**對應且尚未加入之學員執行補邀請並每人寄通知信（統一範本），既有學員不受影響。
    > **2026-10-19 #720 補充——補邀請與通知信的時點**：受訓對象配對自本次變更起與基本資料一同進入編輯暫存區（見 FR-ET-US3-14），故「新增配對 → 補邀請 → 寄通知信」MUST 於教師按下生效鈕（「更新」／「更新並重開課」）之後執行，MUST NOT 於編輯當下執行。
    > 於編輯當下寄信會寄出一件尚未發生的事：信中告知學員已被加入某課程，而該配對仍在暫存區、他點進去看不到任何東西；教師若接著按「取消」，該配對從未存在而信已寄出。
    > **「可移除 / 不可移除」之判定仍以活表（學員目前看得到的那一份）為準**——教師本輪自行加入暫存、尚未生效即又移除的配對無人看過，MUST NOT 被此限制擋下。
    > **#586 改訂理由**：原條文只規範「草稿」與「已發布」，**未涵蓋「已關閉」**，程式遂以「非草稿一律比照已發布」補白，與本意相反。SA 裁示 A：關閉是教師的手動動作（US11），即視為「回到可整理狀態」，教師有權重新定義受訓對象。
    > **#586 已知且接受的後果**：教師可藉「關閉 → 移除 → 再開課」繞過已發布之限制，使課程顯示的受訓對象與實際在課學員之母體不一致（既有學員**不會**被移出課程）。擋下需保存「關閉前的配對」，而 `ET_COURSE_TAG` 就地增刪、無歷史表，成本不相稱，故接受。
    > **#538 改訂理由**：受訓對象改為「單位 + 職位」配對，見 [spec.md](spec.md) §受訓對象規則（#538）。
    > **原條文**：系統 MUST 於「草稿」課程允許自由增刪受訓單位標籤；於「已發布」課程僅允許新增標籤（不可移除，移除鈕不顯示），新增標籤時對該標籤對應且尚未加入之學員執行補邀請並每人寄通知信（統一範本），既有學員不受影響。
- **FR-ET-US3-03**（2026-10-06 由 #538 改訂）: 系統 MUST 於受訓對象選單排除已停用之單位與職位；課程既有配對中之停用標籤保留、不受影響。
    > **改訂理由**：受訓對象改為「單位 + 職位」配對，見 [spec.md](spec.md) §受訓對象規則（#538）。
