# ET02 課程建立與編輯

## 作業說明

### 使用情境

本作業供教師建立一門課程的完整內容——課程基本資料、章節、教材、測驗、課後問卷——並於內容齊備後發布。課程發布後，系統依課程所掛的受訓單位標籤，自動將對應學員加入課程並各寄一封通知信，學員即可於「我的課程」看到這門課程。

課程建立後的後續作業銜接如下：學員的學習狀況於 ET03 學員查看；學員端的學習與作答於 ET05 課程學習、ET06 線上測驗進行。

課程的擁有者於建立當下記錄，**永久不可變更、亦不可轉讓**。其他教師或管理者開啟這門課程時進入檢視模式，畫面上方會顯示由誰建立，所有欄位停用、操作按鈕不顯示。

進入本作業需具教師角色；管理者可由課程列表開啟課程檢視，但同樣不能編輯非本人建立的課程。

> 重要：擁有者不可轉讓。建立課程的教師若日後帳號停用，該課程即無人可再編輯——課程列表的建立者會顯示為「姓名（已停用帳號）」。需要異動時只能由其他教師另建一門課程。

### 進入路徑

側邊選單「教育訓練 → 課程列表」，再依下表其中一種方式進入：

| 要做的事 | 進入方式 |
|---|---|
| 建立新課程 | 點篩選列右側的「新增課程」 |
| 編輯既有課程 | 於「我建立的」分頁點該課程卡片 |
| 檢視他人課程 | 於「全部課程」分頁點該課程卡片（唯讀） |

「新增課程」僅具教師角色者看得到。

## 操作說明

### 畫面與前置設定

畫面自上而下依序為：標題列（課程狀態標記與右上操作按鈕）、基本資料、章節編排、課後問卷，最下方為固定於畫面底部的動作列。

課程狀態決定畫面上出現哪些操作：

| 課程狀態 | 標題列右上 | 底部動作列 |
|---|---|---|
| 草稿 | 不顯示操作按鈕 | 取消、儲存草稿、儲存並發布 |
| 已發布 | 邀請學員、關閉課程 | 取消、儲存 |
| 已關閉 | 再開課 | 取消、儲存 |

「儲存並發布」只在草稿狀態出現。已發布課程的編輯**即時生效、不需重新發布**，因此沒有再發布一次的按鈕。

下列前置資料由管理者於平台後台維護，教師無法自行新增，缺漏時請先請管理者處理：

| 前置資料 | 影響 |
|---|---|
| 受訓單位標籤 | 課程只能掛「啟用中」的標籤；標籤決定發布時自動邀請哪些學員 |
| 訓練教材文件 | 教材可引用的文件僅來自文件管理「訓練教材」分類之已發布文件 |
| 通知信範本 | 發布與邀請所寄出的信件，主旨與內文統一維護，教師不可逐課修改 |

### 建立課程基本資料

1. 填寫「課程名稱」
2. 於「受訓單位標籤」選取適用對象（可多選）
3. 設定「課程起始時間」與「課程訖止時間」
4. 需要線下考核者，開啟「本課程需線下核可」
5. 「課程描述」選填，至多 500 字
6. 按底部「儲存草稿」

> 重要：草稿階段**只有課程名稱必填**。受訓單位標籤與起訖時間留空仍可存成草稿，但發布時會被擋下。

各欄位在畫面上看不出來的規則：

| 欄位 | 看不出來的地方 |
|---|---|
| 受訓單位標籤 | 決定發布時自動邀請誰。草稿可自由增刪；**課程一經發布，既有標籤即不可移除**（標籤上的移除鈕消失），只能新增 |
| 課程起始時間 | 起始時間到達前，課程於學員端完全不顯示、學員也無法進入學習；教師端不受影響，仍可正常編輯 |
| 課程訖止時間 | 到達訖止時間時系統自動將課程轉為「已關閉」，不需教師操作 |
| 本課程需線下核可 | 學員線上完課後仍須教師或管理者另行核可。此設定**不影響完課率**，且草稿、已發布、已關閉狀態皆可調整 |

起始時間不可設為過去的時間；但已開課的課程再次編輯時，原本就落在過去的起始時間可以沿用，只是不能再往前調整。

按「儲存草稿」後畫面會**回到課程列表**，不會停留在編輯頁。章節、教材、測驗與問卷各自即時儲存，不會因離開編輯頁而遺失。

> 注意：已發布課程按「儲存」後，畫面同樣顯示「草稿已儲存」並回到課程列表。這不表示課程被退回草稿，課程狀態不會改變。

**已發布後新增標籤會立刻寄信**

已發布課程新增一個受訓單位標籤並儲存後，系統對該標籤對應、且尚未加入本課程的學員執行補邀請並逐一寄出通知信；已在課程中的學員不受影響、不會重複收信。

### 編排章節

於「章節編排」區按「新增章節」，於視窗中填章節名稱後儲存。需要連續建立多個章節時，按「儲存並繼續新增」可留在視窗中接著填下一個。

章節建立後可直接於列上修改名稱，**游標離開欄位即自動儲存**，沒有另外的儲存按鈕。

拖曳章節左側的手把可調整順序；章節內的教材與測驗同樣以手把拖曳調整。學員必須依序完成每個章節才能進入下一章，此規則系統內建，不需逐章設定。

> 重要：刪除章節會**連帶移除學員在該章節的學習紀錄與測驗成績**，且不再計入完課率。刪除前會跳出確認視窗，確認後後續章節的順序自動往前遞補。

**新增課程時按「新增項目」會先自動存草稿**

課程尚未建立時，教材與測驗沒有可以掛載的位置。因此在新增課程的畫面按「新增項目」，系統會先自動把課程存成草稿（畫面顯示「已自動儲存草稿」）並轉入該課程的編輯頁，再開啟項目視窗。這是正常流程，不是操作失敗；此時課程已經建立，重新整理或離開都不會遺失。

### 新增教材

於章節內按「新增項目 → 教材」，開啟教材編輯視窗。教材由三類素材自由組合，至少要提供其中一項：

| 素材 | 說明 |
|---|---|
| 說明文字 | 於編輯器直接撰寫 |
| 影片檔 | 支援 mp4 / webm，單檔最大 500 MB；長度由系統自動解析 |
| 教材文件 | 自文件管理「訓練教材」分類選取 |

填寫「項目標題」後按「儲存」。

> 重要：**影片是選檔後立即上傳**，其餘變更（標題、說明文字、文件引用的增刪）一律按「儲存」才生效。因此上傳影片後才按「取消」，影片仍會留在教材中，需要再開啟教材將它移除。

引用文件時，下拉只列出已發布的文件。引用後**恆帶最新發布版本**——文件管理端改版後，學員下次開啟章節即取得新版，教師不需回頭更新。

引用的文件若被廢止，該筆旁邊會顯示「此文件已廢止」標籤，而且**課程會因此無法發布**。處理方式是開啟該教材編輯視窗，逐筆移除廢止文件的引用，系統不提供批次移除。若顯示的是「文件已失效」，表示該文件在文件管理端已取不到，同樣需要移除引用。

### 建立測驗與題目

於章節內按「新增項目 → 測驗」，開啟測驗編輯視窗。視窗分「測驗設定」與「題庫管理」兩個分頁。

「測驗設定」分頁填寫下列欄位後按「儲存」：

| 欄位 | 看不出來的地方 |
|---|---|
| 及格分數 | 預設 80，範圍 0 至 100 |
| 作答時間限制 | **留空表示不限時**；填入數字即為限時分鐘數 |
| 重考次數上限 | 預設 3，範圍 0 至 999；**填 0 表示不允許重考** |
| 測驗說明 | 選填，顯示於學員按下開始作答之前 |

「題庫管理」分頁按「新增題目」逐題建立。每題設定題型（單選或多選）、題幹、配分與選項，單選以圓鈕標記唯一正確答案、多選以核取方塊勾選所有正確答案。每題選項數為 2 至 6 個，配分範圍 1 至 100 分。填妥後按該題的「儲存題目」。

> 重要：題目一次只能展開編輯一題，且題目是**逐題各自儲存**的。底部的「儲存」只存測驗設定，不會儲存展開中的題目；關閉視窗會讓展開中、尚未按下「儲存題目」的內容消失。

分頁上方常駐顯示「配分總和 N / 100」。**總和不等於 100 時不會阻擋儲存**，但會在發布課程時被擋下——逐題建立的過程中總和本來就不會是 100，此處只是提醒。

題目呈現給學員的順序由系統自動洗牌，教師不需也無法指定，因此題庫沒有拖曳排序的手把。

> 重要：刪除題目會**連帶移除學員在該題的作答紀錄與得分**。確認後即不再計分。

### 建立課後問卷

課後問卷掛在課程層級，一門課程最多一份，且為選配——沒有建立問卷不會影響課程發布。學員完課後才會開放填寫，採具名、一人一次；**填寫問卷不是完課條件，也不計入學習進度**。

於「課後問卷」區按「新增問卷」，填問卷名稱後按「建立」。建立後按「編輯」開啟問卷視窗逐題撰寫。

問卷題目有兩種題型：

| 題型 | 教師要填的內容 | 學員如何作答 |
|---|---|---|
| 單選 | 題幹與至少 2 個選項（無上限） | 選擇其中一個選項 |
| 問答 | 只填題幹，不可有選項 | 以文字作答，至多 150 字 |

由單選改為問答時，原本已填的選項會被清空。

問卷尚無題目時，視窗內會出現「套用模板」，可一次帶入一組常用題目，套用後即為一般題目、可自由增刪修改。**已有題目後就不再提供模板**，需要改用模板內容時得先把既有題目刪除。

> 重要：**一旦有任何學員填答，題目與選項即凍結**，不能再修改或刪除，視窗上方會顯示凍結提示。此時只能停用問卷——停用後學員端不再顯示填寫入口，已填寫的內容仍然保留。問卷名稱不在凍結範圍內，隨時可改。

刪除與停用是互補的，不會同時出現：

| 課程狀態 | 問卷可用的操作 |
|---|---|
| 草稿 | 刪除（連同題目與選項一併移除，之後可重新建立） |
| 已發布、已關閉 | 停用 |

### 發布課程

按底部「儲存並發布」。系統會先把目前的編輯內容存檔，再開啟視窗逐項檢核下列六項條件：

| 檢核項目 | 要求 |
|---|---|
| 章節 | 至少 1 個章節 |
| 教材 | 至少 1 份教材 |
| 受訓單位標籤 | 至少 1 個 |
| 課程起訖時間 | 起、訖兩個時間都要填 |
| 測驗 | 每份測驗至少 1 題，且各題配分總和等於 100 |
| 教材文件 | 沒有引用已廢止的文件 |

課程若已建立課後問卷，該問卷也必須至少有 1 題，否則一併擋下；不想出問卷時可將問卷停用。

未通過時視窗會逐條列出缺漏，並指出該去哪個區塊補；補齊後重新按一次「儲存並發布」。通過時按「確認發布」完成發布。

發布當下系統會連續做四件事：

1. 課程狀態轉為「已發布」
2. 產生一組 8 碼數字邀請碼
3. 依課程所掛的受訓單位標籤，把對應且具學員角色的人員加入課程（多個標籤取聯集、重複者只加入一次；掛「全體」標籤即為全部學員）
4. 對每位被加入的學員各寄一封通知信

> 重要：邀請碼**發布後永久不可變更，也不提供重新產生**。它常駐顯示於編輯頁上方，可按旁邊的複製鈕取用。

發布後仍可繼續編輯課程內容，儲存即生效，不需要再發布一次。但**新增章節會影響既有學員**：系統會自動寄信通知所有已加入的學員，且已完課學員的完課狀態會回退為「進行中」（學員已填寫的課後問卷不會失效、不需重填）。

### 邀請學員

「邀請學員」按鈕僅於課程「已發布」時顯示於標題列右上；草稿與已關閉狀態不顯示，再開課後會恢復。

學員的主要來源是**發布當下的標籤自動邀請**，本視窗供補件之用，分兩個分頁：

**Email 邀請**

供臨時追加不在標籤內的人。於「學員 Email」欄輸入名單，每行一筆或以逗號分隔，單次至多 50 筆，按「下一步」顯示邀請信預覽，確認後按「確認寄出」。

> 重要：收件對象**限已建立帳號者**。名單中只要有一筆查無帳號，整批都不會寄出，畫面會列出是哪幾筆；需要邀請尚無帳號的人員時，得先請管理者建立帳號。

預覽的主旨與內文不可編輯，且**不會帶入任何一位收件人的資料**——稱謂與邀請連結逐人不同，於寄出時才各自產生，預覽中以佔位字樣呈現。因此更動收件名單後不需要重新預覽。

每位收件人拿到的邀請連結是一次性的，被使用後即失效，不可轉寄。

**邀請碼**

顯示本課程的 8 碼邀請碼與 QR Code，並提供「複製邀請連結」與「複製邀請碼」。學員於「我的課程 → 加入新課程」輸入此碼即可自行加入。

> 重要：邀請碼於課程**關閉期間失效**，學員會被擋下；再開課後自動恢復有效。

### 關閉課程與再開課

課程關閉有兩種情形，效果完全相同：

| 情形 | 說明 |
|---|---|
| 到期自動關閉 | 到達課程訖止時間時由系統自動轉為「已關閉」，不需教師操作 |
| 手動關閉 | 教師按標題列右上的「關閉課程」，確認後立即生效 |

按「關閉課程」會跳出確認視窗，說明關閉後會停掉哪些事；按「確認關閉」後課程立即轉為「已關閉」。

關閉後各方受到的影響：

| 對象 | 關閉後 |
|---|---|
| 學員 | 課程仍留在「我的課程」並標示已關閉，可**唯讀回看**已學過的內容與成績；不能再累積進度、開始新的測驗作答、解鎖新章節或填寫問卷 |
| 正在作答的學員 | 當下那次作答**可以完成並計分**，交卷後不能再開始新的作答 |
| 教師 | 課程內容**仍可編輯**，供整理後再開課；但不能邀請學員（按鈕隱藏）、不能重置重考次數 |
| 邀請碼與 Email 邀請 | 暫時失效 |

> 重要：關閉是**可逆**的，不是終止課程。關閉期間編輯頁上方會有提示說明課程內容仍可編輯。

再開課時按標題列右上的「再開課」，於視窗中重新設定一組新的開放起訖時間。兩個時間**都必須重新指定，系統不會帶入原本的值**；未填妥不能送出。按「確認再開課」後課程回到「已發布」。

再開課會**重新跑一次發布的六項檢核**——關閉期間的編輯可能把必要內容移除了。有缺漏時視窗會逐條列出，補齊後再按一次「確認再開課」即可，不需關掉視窗重開。

再開課後：學員的學習進度與成績**接續保留、不會歸零**；原邀請碼沿用並恢復有效；統計與提醒恢復納入該課程。關閉與再開課可以重複多次。

## 常見訊息與處置

### 被擋下（動作沒有完成）

**基本資料**

| 訊息 | 處置 |
|---|---|
| 「請輸入課程名稱」 | 課程名稱為必填 |
| 「課程起始時間不可早於目前時間」 | 改選現在之後的時間 |
| 「課程已開課，起始時間不可再往前調整」 | 已開課的課程可沿用原起始時間，但不能往前挪 |
| 「課程訖止時間須晚於起始時間」 | 檢查兩個時間的先後 |
| 「已發布課程不可清空閱課結束時間，如需停止請改用關閉課程」 | 已發布課程必須有訖止時間；要停止課程請用「關閉課程」 |
| 「已發布課程不可移除既有標籤」 | 課程發布後標籤只能新增 |
| 「指定之受訓單位標籤無效或未啟用」 | 該標籤已被管理者停用，請改選其他標籤 |

**教材**
