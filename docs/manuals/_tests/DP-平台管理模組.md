# 平台管理模組

## DP00 登入後主頁

### 測試前準備

| 項目 | 說明 |
|---|---|
| 已加入數門課程的學員帳號 | 1 組（第 2、3 項） |
| 已發布、閱課起始時間在明天以後的課程（含邀請碼） | 1 門（第 3 項） |
| 教育訓練管理者帳號 | 1 組（第 4 項） |
| 教師帳號，且為下列課程的開課教師 | 1 組（第 5、6 項） |
| 該教師的已發布課程：一門尚有學員未完成、一門學員已全數完成 | 2 門（第 5 項） |
| 該教師的草稿課程 | 1 門（第 6 項） |

### 測試項目清單

| 項次 | 測試內容 |
|---|---|
| 1 | 以任一帳號登入，應進入本頁並於上方顯示「歡迎，」加上登入者姓名；於任一作業畫面按頂列的「教育訓練文件管理系統」應回到本頁，按頂列右上的姓名應進入 DP10 個人資料維護。 |
| 2 | 以已加入數門課程的學員帳號登入，「我的學習概況」的進行中、未開始、已完成、未開放四個數字應與 ET03 我的課程頁上方統計相同；按其下方的「前往我的課程」應進入 ET03 我的課程。 |
| 3 | 以已加入數門課程的學員帳號，用邀請碼加入一門閱課起始時間在明天以後的課程後回到本頁，「未開放」應加一，「未開始」不變。 |
| 4 | 以教育訓練管理者登入，「全體訓練概況」應列出已有學員之已發布與已關閉課程。 |
| 5 | 以教師登入，先記下本人兩門已發布課程（一門尚有學員未完成、一門學員已全數完成）的閱課結束時間，於 ET05 將兩門皆暫改為兩天後並更新；回到本頁，「我的課程待辦」應列出尚有學員未完成的那門及其剩餘天數與未完課人數（剩餘天數以整天無條件捨去，例如剩 47 小時顯示「剩 1 天」），學員已全數完成的那門不應列出。測畢將兩門的閱課結束時間改回原值，否則次日排程會寄出截止提醒信。 |
| 6 | 同一教師有草稿課程時，「我的課程待辦」應顯示「有 N 門課程尚未發布。」，N 與 ET01 課程列表中本人的草稿數相同；按「我的課程待辦」中的課程列應進入該課程的編輯頁，按「前往課程列表」應進入 ET01 課程列表。 |

## DP01 使用者管理

### 測試前準備

| 項目 | 說明 |
|---|---|
| 具教育訓練或文件管理任一模組管理者角色之帳號 | 1 組（全部項目） |
| 另一個模組的管理者帳號 | 1 組（第 1 項；兩模組管理者為同一人時此項驗不到。環境中若沒有單一模組管理者，可先於 DP02 權限管理暫時授予另一帳號該模組的管理者角色，測畢收回） |
| 尚未在系統中使用過、且測試當下收得到信的 Email | 1 個（第 4～6、8～10 項） |
| 已完成啟用的帳號 | 1 組（第 7、11 項） |
| 可犧牲的啟用中帳號（會被停用、鎖定） | 1 組（第 13～16 項） |
| 第二個瀏覽器或裝置 | 第 13 項需一邊以管理者停用、另一邊以該使用者操作） |

### 測試項目清單

| 項次 | 測試內容 |
|---|---|
| 1 | 以教育訓練管理者與文件管理管理者分別進入本作業，兩者看到的帳號與狀態應相同（「最後登入」欄會因各自剛登入而不同，不列入比對）。 |
| 2 | 以「關鍵字（姓名 / Email）」「帳號狀態」任一條件或組合查詢，清單應只列出符合條件的帳號。 |
| 3 | 於「關鍵字（姓名 / Email）」輸入後，清單應自動更新，不需另按查詢鈕。 |
| 4 | 按「建立帳號」填入一個尚未在系統中使用過、且收得到信的 Email 與姓名（以下稱**受測 Email**），按「寄送邀請」並確認，該筆應出現在「待啟用邀請」頁籤、頁籤上的數字等於該清單的實際筆數，「帳號」頁籤不應出現該筆。 |
| 5 | 收受測 Email 的邀請信並於效期內點連結設定密碼後，該筆應自「待啟用邀請」消失，並出現在「帳號」頁籤、狀態為啟用中。 |
| 6 | 受測 Email 完成設定密碼後，以該 Email 登入應可直接進入系統、不再要求變更密碼；於 DP02 權限管理查看該使用者，應已具教育訓練的學員角色。 |
| 7 | 以**已完成啟用之帳號**的 Email 建立帳號，應擋下並提示該 Email 已被使用，且不產生新的邀請。 |
| 8 | 以受測 Email 重新寄出一筆邀請後，再以同一 Email 建立一次帳號，應擋下並提示改用重寄，且不產生第二筆邀請。 |
| 9 | 對上述有效中的邀請按「重寄邀請」，應顯示已重寄，原連結應失效、新連結可正常設定密碼；立即再按一次「重寄邀請」，應被擋下並顯示尚需等待的分鐘數。 |
| 10 | 自上述邀請寄出起，等候 DP03 系統參數與清單維護的「密碼重設連結有效時間（分鐘）」（預設 30 分鐘）屆滿後查看「待啟用邀請」，該筆邀請狀態應顯示「已逾期」，且其連結無法再設定密碼；對其按「取消邀請」並確認，該筆應自清單消失，且該 Email 可重新建立帳號。 |
| 11 | 對一個已完成啟用的帳號按「編輯」，「帳號（Email）」欄位應為唯讀不可輸入；修改「姓名」後按「儲存」並確認，清單該列姓名應更新為新值，Email 不變。 |
| 12 | 本人帳號那一列的「停用」應為灰色無法按，滑鼠移上去顯示「無法停用自己的帳號」；他人帳號那一列的「停用」可正常按。 |
| 13 | 選一個可犧牲的啟用中帳號（以下稱**受測帳號**），於第二個瀏覽器以受測帳號登入並停留在教育訓練或文件管理的任一頁面；回到管理者的瀏覽器對受測帳號按「停用」並確認，該列狀態應變為「已停用」、按鈕改為「啟用」，而受測帳號那一邊的下一個操作應立即回到登入畫面並顯示「帳號已停用，請洽管理者」，不需等待其閒置登出。 |
| 14 | 對已停用的受測帳號按「啟用」，狀態應恢復為「啟用中」，該帳號可再次登入。 |
| 15 | 以受測帳號連續輸入錯誤密碼至被鎖定（次數上限為 DP03 的「登入失敗鎖定次數」，預設 5 次）後，於本作業對其按「解鎖」，狀態應恢復為「啟用中」，該帳號可立即以正確密碼登入。 |
| 16 | 再次以受測帳號連續輸錯密碼至被鎖定，不做解鎖，等候 DP03 的「帳號鎖定時間（分鐘）」（預設 30 分鐘）屆滿後重新查詢該帳號，狀態應已自動恢復為「啟用中」，不需人工解鎖。 |

## DP02 權限管理

### 測試前準備

| 項目 | 說明 |
|---|---|
| 同時具教育訓練與文件管理管理者身分之帳號 | 1 組（全部項目） |
| 只具其中一個模組管理者身分之帳號 | 1 組（第 1 項；兩個帳號都是雙模組管理者時這項驗不到。環境中若沒有，可先於本作業暫時授予另一帳號該模組的管理者角色，測畢收回） |
| 啟用中、具學員角色、不具任何文件管理角色、角色可自由增減且知道密碼之帳號（勿用測試者本人） | 1 組（第 5、7～12 項） |
| 已停用、且已持有至少一個文件管理角色之帳號 | 1 組（第 4 項。可先於本作業指派一個角色，再於 DP01 使用者管理停用取得） |
| DP03 系統參數與清單維護中，文件管理與教育訓練的「單位」「職位」各至少 2 項且為啟用中 | 第 8～12 項（兩模組清單各自獨立，需分別確認） |
| 已發布未關閉、受訓對象含一組具體「單位 + 職位」配對（非「全單位」「全體」）之課程 | 1 門（第 11、12 項。上述受指派帳號尚未加入該課程、受訓對象為「未指派」，且不得為該課程的建立者） |

### 測試項目清單

| 項次 | 測試內容 |
|---|---|
| 1 | 以僅具單一模組管理者身分的帳號進入本作業，應只看到該模組的分頁；具兩模組管理者身分者應看到兩個分頁。 |
| 2 | 以「關鍵字（姓名 / Email）」查詢，清單應只列出符合條件的使用者。 |
| 3 | 於「關鍵字（姓名 / Email）」輸入後，清單不應自動更新，按「查詢」或 Enter 後才套用篩選。 |
| 4 | 於文件管理分頁查詢一個已停用的帳號，該列應標示「已停用」，其角色核取方塊與「編輯」皆不可操作——**連已持有的角色也不可取消**。 |
| 5 | 選一個啟用中、角色可自由增減的帳號（以下稱**受測使用者**），勾選其一個角色，畫面應顯示「角色 / 標籤已更新並即時生效」且無須另按儲存，重新查詢後該勾選仍在；再同時勾選兩個以上角色，應全部可並存（權限取聯集）。 |
| 6 | 對自己目前登入的帳號取消管理者角色，應被擋下並提示無法取消自己的管理者角色。 |
| 7 | 為受測使用者勾選文件管理的閱覽者後，以受測使用者登入應可進入文件管理的功能，不需重新指派或等待。 |
| 8 | 於文件管理分頁對受測使用者按「編輯」，新增一組「單位 + 職位」並儲存，該列的可見對象欄應顯示該組配對；再移除一組既有的可見對象並儲存，該組應自欄位消失，其餘組別不受影響。 |
| 9 | 於文件管理分頁對受測使用者按「編輯」，新增一列只選「單位」未選「職位」即按「儲存」，視窗不應關閉、職位欄應標出紅框並提示補選或刪除；按該列的移除鈕後再儲存，可見對象欄不應出現該列。 |
| 10 | 於教育訓練分頁對受測使用者按「編輯」，視窗應同樣以「單位」「職位」兩個下拉呈現；新增兩組配對並儲存，該列的受訓對象欄應同時顯示兩組。 |
| 11 | 選一門已發布未關閉、受訓對象含一組具體「單位 + 職位」配對的課程（以下稱**受測課程**，其配對稱**受測配對**），於教育訓練分頁為受測使用者新增一組「與受測配對職位相同、但單位不同」的配對並儲存，該員**不應**出現在受測課程的學員清單中。 |
| 12 | 為同一位受測使用者再新增受測配對本身並儲存，以受測課程的教師帳號於 ET02 學員學習表現查看該課程（前次若已開著該頁，先離開再進入，否則清單不會更新），該員應已在學員清單中，並收到一封列出該課程的通知信。 |

## DP03 系統參數與清單維護

### 測試前準備

| 項目 | 說明 |
|---|---|
| 同時具教育訓練與文件管理管理者身分之帳號 | 1 組（第 2～8 項） |
| 只具文件管理管理者身分之帳號 | 1 組（第 1 項。環境中若沒有，可先於 DP02 權限管理暫時授予另一帳號該模組的管理者角色，測畢收回） |
| 具文件管理編輯者角色之帳號 | 1 組（第 5、6 項，用於在 DM08 文件新增與編輯確認分類下拉） |
| 文件管理單位清單中，至少一組配對設定（文件可見對象或使用者對象）已用到的單位 | 1 個（第 7 項） |

### 測試項目清單

| 項次 | 測試內容 |
|---|---|
| 1 | 以只具文件管理管理者身分的帳號進入，應只看到「平台（共用）」與「文件管理（DM）」兩個分頁；兩模組管理者應看到三個分頁。 |
| 2 | 先記下「登入失敗鎖定次數」的原值，修改後按「儲存」，應先跳出平台級確認視窗；按「取消」後欄位應還原為修改前的值，再按「儲存」並「確定儲存」應提示「已儲存並即時生效」，清單上的參數值隨即更新。測畢將該參數改回原值。 |
| 3 | 將「帳號鎖定時間（分鐘）」設為 1441 並儲存，應被擋下並提示參數值不合法，參數值維持原值；將「密碼到期提醒天數」設為與「密碼最長效期」相同並儲存，亦應被擋下並提示參數值不合法。 |
| 4 | 先記下文件管理分頁「催辦門檻天數」的原值，修改並儲存，不應跳出平台級確認視窗，應直接提示「已儲存並即時生效」。測畢將該參數改回原值。 |
| 5 | 於「文件分類」填入一組**從未使用過**的英文代碼（例如 ZT 加當天日期，分類建立後無法刪除、同一代碼只能測一次）與名稱後按「新增」，該分類應出現在清單中，且於 DM08 新增文件時的分類下拉可選；再以相同代碼新增一次，應被擋下並提示分類碼已存在。 |
| 6 | 將上項新增的分類改名並按同列「儲存」，DM08 的分類下拉應顯示新名稱，該列代碼應無法修改；對該分類按「停用」並「確定停用」，應標示「已停用」且 DM08 的分類下拉不再列出，按「啟用」後應恢復可選。測畢將該分類停用。 |
| 7 | 停用一個已被配對設定用到的單位，結果訊息應為「已停用，影響 N 組文件可見對象設定、M 組使用者對象設定」，N、M 為正整數或 0（為配對組數，不是文件份數或人數）。測畢將該單位重新啟用。 |
| 8 | 於教育訓練職位清單將「全體」改名並儲存，應被擋下並提示為系統內建通用值；對其按「停用」並確認，亦應被擋下。 |

## DP05 操作記錄查詢

### 測試前準備

| 項目 | 說明 |
|---|---|
| 具教育訓練或文件管理管理者身分之帳號 | 1 組（全部項目） |

### 測試項目清單
