# 平台管理模組

## DP00 登入後主頁

### 測試前準備

| 項目 | 說明 |
|---|---|
| 學員帳號 | 已加入數門課程的帳號，例如示範審核者（reviewer@edms.local，已加入 5 門），用於第 2、3 項 |
| 尚未開放的課程 | 第 3 項需一門**已發布、閱課起始時間在明天以後**的課程，並取得其邀請碼；由教師帳號建立並發布即可 |
| 管理者帳號 | 具教育訓練管理者角色者，例如示範管理者（admin@edms.local），用於第 4 項 |
| 教師帳號 | 例如示範教師（teacher@edms.local），用於第 5、6 項，需為下列課程的開課教師 |
| 即將截止的課程 | 第 5 項需兩門教師本人的已發布課程，閱課結束時間皆暫調為兩天後：一門**尚有學員未完成**、另一門**學員已全數完成**。測前先於主頁「全體訓練概況」確認兩門的完成人數，並記下原結束時間；**測畢兩門皆改回原結束時間**，否則次日排程會寄出截止提醒信 |

### 測試項目清單

| 項次 | 測試內容 |
|---|---|
| 1 | 以任一帳號登入，應進入本頁並於上方顯示「歡迎，」加上登入者姓名；於任一作業畫面按頂列的「教育訓練文件管理系統」應回到本頁，按頂列右上的姓名應進入 DP10 個人資料維護。 |
| 2 | 以學員帳號登入，「我的學習概況」的進行中、未開始、已完成、未開放四個數字應與 ET03 我的課程頁上方統計相同；按其下方的「前往我的課程」應進入 ET03 我的課程。 |
| 3 | 學員以邀請碼加入一門尚未到起始時間的課程後回到本頁，「未開放」應加一，「未開始」不變。 |
| 4 | 以管理者登入，「全體訓練概況」應列出已有學員之已發布與已關閉課程。 |
| 5 | 以教師登入，本人課程之閱課結束時間在 3 天內且仍有學員未完成時，「我的課程待辦」應列出該課程、剩餘天數與未完課人數（剩餘天數以整天無條件捨去，例如剩 47 小時顯示「剩 1 天」）；閱課結束時間同樣在 3 天內、但學員已全數完成的課程不應列於其中。 |
| 6 | 教師本人有草稿課程時，「我的課程待辦」應顯示「有 N 門課程尚未發布。」，N 與課程列表中本人的草稿數相同；按「我的課程待辦」中的課程列應進入該課程的編輯頁，按「前往課程列表」應進入 ET01 課程列表。 |

## DP01 使用者管理

### 測試前準備

| 項目 | 說明 |
|---|---|
| 管理者帳號（主要） | 具教育訓練或文件管理任一模組之管理者角色，本作業絕大多數項目以此帳號操作 |
| 管理者帳號（另一模組） | 另一個模組的管理者帳號，用於驗證帳號為兩模組共用、所見相同（第 1 項）；兩模組管理者為同一人時此項驗不到。GCP 等環境若沒有單一模組管理者帳號，可先於 DP02 權限管理暫時授予另一帳號（例如教師帳號）該模組的管理者角色，測畢收回 |
| 可收信的 Email | 一個**尚未在系統中使用過**且測試當下收得到信的 Email，用於建立帳號與完成啟用（第 3 項）；收不到信則整段啟用流程驗不到 |
| 已存在之帳號 | 一個已完成啟用的帳號，用於驗證 Email 重複（第 4 項）與編輯姓名（第 9 項） |
| 鎖定中之帳號 | 以某帳號連續輸入錯誤密碼至被鎖定（失敗次數上限為系統參數，可於 DP03 系統參數與清單維護查得），用於第 13 項。第 14 項需等鎖定期滿，鎖定時間為 DP03 的「帳號鎖定時間（分鐘）」，預設 30 分鐘 |
| 已逾期之邀請 | 一筆邀請狀態為「已逾期」者（第 7 項）。邀請效期即 DP03 的「密碼重設連結有效時間（分鐘）」，預設 30 分鐘，寄出邀請後等候逾時即可取得（調短此參數會一併影響忘記密碼連結，不建議） |
| 跨模組驗證用環境 | 受測使用者需在教育訓練或文件管理至少有一個可操作的頁面，且需一邊以管理者停用、另一邊以該使用者操作，用於第 11 項 |

### 測試項目清單

| 項次 | 測試內容 |
|---|---|
| 1 | 以教育訓練管理者與文件管理管理者分別進入本作業，兩者看到的帳號與狀態應相同（「最後登入」欄會因各自剛登入而不同，不列入比對）。 |
| 2 | 以關鍵字（姓名 / Email）、帳號狀態任一條件或組合查詢，清單應只列出符合條件的帳號；關鍵字輸入後清單應自動更新，不需另按查詢鈕。 |
| 3 | 按「建立帳號」填入未使用過的 Email 與姓名，按「寄送邀請」並確認，該筆應出現在「待啟用邀請」頁籤、頁籤上的數字等於該清單的實際筆數，「帳號」頁籤不應出現該筆；收信並於效期內點連結設定密碼後，該筆應自「待啟用邀請」消失並出現在「帳號」頁籤、狀態為啟用中；以該 Email 登入應可直接進入系統、不再要求變更密碼，於 DP02 權限管理查看該使用者應已具教育訓練的學員角色。 |
| 4 | 以**既有帳號**的 Email 建立帳號，應擋下並提示該 Email 已被使用，且不產生新的邀請。 |
| 5 | 以**已有有效中待啟用邀請**的 Email 再建立一次，應擋下並提示改用重寄，且不產生第二筆邀請（邀請已逾期者會直接重新寄出，不適用本項）。 |
| 6 | 對一筆有效中的邀請按「重寄邀請」，應顯示已重寄，原連結應失效、新連結可正常設定密碼；立即再按一次「重寄邀請」，應被擋下並顯示尚需等待的分鐘數。 |
| 7 | 邀請逾期後查看「待啟用邀請」，該筆邀請狀態應顯示「已逾期」，且其連結無法再設定密碼。 |
| 8 | 對一筆邀請按「取消邀請」並確認，該筆應自清單消失，且該 Email 可重新建立帳號。 |
| 9 | 對某帳號按「編輯」，「帳號（Email）」欄位應為唯讀不可輸入；修改「姓名」後按「儲存」並確認，清單該列姓名應更新為新值，Email 不變。 |
| 10 | 本人帳號那一列的「停用」應為灰色無法按，滑鼠移上去顯示「無法停用自己的帳號」；他人帳號那一列的「停用」可正常按。 |
| 11 | 對一個啟用中的帳號按「停用」並確認，該列狀態應變為「已停用」、按鈕改為「啟用」；該使用者若仍在使用中，於教育訓練或文件管理的下一個操作應立即回到登入畫面並顯示「帳號已停用，請洽管理者」，不需等待其閒置登出。 |
| 12 | 帳號被停用後，對其按「啟用」，狀態應恢復為「啟用中」，該使用者可再次登入。 |
| 13 | 帳號因連續輸入錯誤密碼而鎖定後，對其按「解鎖」，狀態應恢復為「啟用中」，該使用者可立即以正確密碼登入。 |
| 14 | 帳號鎖定期滿後重新查詢該帳號，狀態應已自動恢復為「啟用中」，不需人工解鎖。 |

## DP02 權限管理

### 測試前準備

| 項目 | 說明 |
|---|---|
| 管理者帳號（兩模組） | 同時具教育訓練與文件管理管理者身分，本作業絕大多數項目以此帳號操作；兩個分頁都要看得到才測得到第 1 項 |
| 管理者帳號（單一模組） | 只具其中一個模組管理者身分者，用於驗證分頁只列出可管理的模組（第 1 項）；兩個帳號都是雙模組管理者時這項驗不到。GCP 等環境若沒有單一模組管理者帳號，可先於本作業暫時授予另一帳號（例如教師帳號）該模組的管理者角色，測畢收回 |
| 受指派的一般使用者 | 一個啟用中、具學員角色、角色可自由增減的帳號，用於第 4、6、9 項。第 6 項需該帳號原本**不具任何文件管理角色**（已有時先取消）。請勿使用測試者本人的帳號，否則會與第 5 項「不可取消本人角色」的檢核混淆 |
| 已停用之帳號 | 一個狀態為「已停用」且**已持有至少一個文件管理角色**的帳號（第 3 項要驗「已持有的角色同樣無法取消」，沒有既有角色就驗不到）。先於本作業文件管理分頁指派一個角色（例如閱覽者），再於 DP01 使用者管理停用取得 |
| 可見對象選項 | DP03 系統參數與清單維護中，文件管理的「單位」與「職位」各至少 2 項且為啟用中 |
| 受訓對象選項 | DP03 系統參數與清單維護中，教育訓練的「單位」與「職位」各至少 2 項且為啟用中（與文件管理的清單各自獨立，需分別確認） |
| 掛配對之已發布課程 | 一門已發布、未關閉的課程，受訓對象含「單位甲 + 職位甲」、但不含「單位乙 + 職位甲」（單位與職位皆不得為「全單位」「全體」；其他課程若也掛「單位甲 + 職位甲」，第 9 項該員會一併被加入、通知信也會一併列出）。受指派的一般使用者尚未加入該課程、受訓對象為「未指派」，且不得為該課程的建立者（第 9 項） |
| 可登入的受測帳號 | 第 6、9 項需以被指派者的身分登入確認，故需知道該帳號的密碼或可重設 |

### 測試項目清單

| 項次 | 測試內容 |
|---|---|
| 1 | 以僅具單一模組管理者身分的帳號進入本作業，應只看到該模組的分頁；具兩模組管理者身分者應看到兩個分頁。 |
| 2 | 以關鍵字（姓名 / Email）查詢，清單應只列出符合條件的使用者；輸入後清單不應自動更新，按「查詢」或 Enter 後才套用篩選。 |
| 3 | 於文件管理分頁查詢已停用帳號，該列應標示「已停用」，其角色核取方塊與「編輯」皆不可操作——**連已持有的角色也不可取消**。 |
| 4 | 勾選某使用者的一個角色，畫面應顯示「角色 / 標籤已更新並即時生效」且無須另按儲存，重新查詢後該勾選仍在；對同一使用者同時勾選兩個以上角色，應全部可並存（權限取聯集）。 |
| 5 | 對自己目前登入的帳號取消管理者角色，應被擋下並提示無法取消自己的管理者角色。 |
| 6 | 為某使用者勾選文件管理的閱覽者後，以該帳號登入應可進入文件管理的功能，不需重新指派或等待。 |
| 7 | 於文件管理分頁按「編輯」，新增一組「單位 + 職位」並儲存，該列的可見對象欄應顯示該組配對；新增一列只選「單位」未選「職位」即按「儲存」，視窗不應關閉、職位欄應標出紅框並提示補選或刪除，按該列的移除鈕後再儲存，可見對象欄不應出現該列；移除一組既有的可見對象並儲存，該組應自欄位消失，其餘組別不受影響。 |
| 8 | 於教育訓練分頁按「編輯」，視窗應同樣以「單位」「職位」兩個下拉呈現；新增兩組配對並儲存，該列的受訓對象欄應同時顯示兩組。 |
| 9 | 為受指派的一般使用者新增「單位乙 + 職位甲」並儲存（職位相同、單位不同），該員**不應**出現在掛「單位甲 + 職位甲」之課程的學員清單中；再為同一使用者新增「單位甲 + 職位甲」並儲存，以該課程的教師帳號於 ET02 學員學習表現查看該課程（前次若已開著該頁，先離開本作業再進入，否則清單不會更新），該員應已在學員清單中，並收到一封列出該課程的通知信。 |

## DP03 系統參數與清單維護

### 測試前準備

| 項目 | 說明 |
|---|---|
| 管理者（兩模組） | 同時具教育訓練與文件管理管理者身分，本作業除第 1 項外皆以此帳號操作 |
| 管理者（單一模組） | 只具文件管理管理者身分（第 1 項）。GCP 等環境若沒有單一模組管理者帳號，可先於 DP02 權限管理暫時授予另一帳號（例如教師帳號）該模組的管理者角色，測畢收回 |
| 編輯者帳號 | 具文件管理編輯者角色，用於在 DM08 文件新增與編輯確認分類下拉（第 5、6 項） |
| 測試用分類代碼 | 一組**從未使用過**的英文代碼，例如 ZT 加當天日期（ZT1020）（第 5、6 項）。分類建立後無法刪除，同一代碼只能測一次，請勿沿用他人測過的代碼；測完請將該分類停用 |
| 已被使用的單位 | 文件管理單位清單中，至少一組配對設定（文件可見對象或使用者對象）用到的單位（第 7 項），測完請重新啟用 |
| 參數原值紀錄 | 第 2、4 項會實際修改參數值，測試前記下原值、測完改回 |

### 測試項目清單

| 項次 | 測試內容 |
|---|---|
| 1 | 以只具文件管理管理者身分的帳號進入，應只看到「平台（共用）」與「文件管理（DM）」兩個分頁；兩模組管理者應看到三個分頁。 |
| 2 | 修改「登入失敗鎖定次數」後按「儲存」，應先跳出平台級確認視窗；按「取消」後欄位應還原為修改前的值，再按「儲存」並「確定儲存」應提示「已儲存並即時生效」，清單上的參數值隨即更新。 |
| 3 | 將「帳號鎖定時間（分鐘）」設為 1441 並儲存，應被擋下並提示參數值不合法，參數值維持原值；將「密碼到期提醒天數」設為與「密碼最長效期」相同並儲存，亦應被擋下並提示參數值不合法。 |
| 4 | 於文件管理分頁修改「催辦門檻天數」並儲存，不應跳出平台級確認視窗，應直接提示「已儲存並即時生效」。 |
| 5 | 於「文件分類」填入新增代碼（測試用分類代碼）與新增名稱後按「新增」，該分類應出現在清單中，且於 DM08 新增文件時的分類下拉可選；再以相同代碼新增一次，應被擋下並提示分類碼已存在。 |
| 6 | 將該分類改名並按同列「儲存」，DM08 的分類下拉應顯示新名稱，該列代碼應無法修改；對該分類按「停用」並「確定停用」，應標示「已停用」且 DM08 的分類下拉不再列出，按「啟用」後應恢復可選。 |
| 7 | 停用已被使用的單位，結果訊息應為「已停用，影響 N 組文件可見對象設定、M 組使用者對象設定」，N、M 為正整數或 0（為配對組數，不是文件份數或人數）。 |
| 8 | 於教育訓練職位清單將「全體」改名並儲存，應被擋下並提示為系統內建通用值；對其按「停用」並確認，亦應被擋下。 |

## DP04 通知範本維護

### 測試前準備

| 項目 | 說明 |
|---|---|
| 管理者（兩模組） | 同時具教育訓練與文件管理管理者身分，本作業除第 1 項外皆以此帳號操作 |
| 管理者（單一模組） | 只具教育訓練管理者身分（第 1 項）。GCP 等環境若沒有單一模組管理者帳號，可先於 DP02 權限管理暫時授予另一帳號（例如教師帳號）該模組的管理者角色，測畢收回 |
| 測試者可收信之信箱 | 一個尚未註冊的 Email 信箱，用於在 DP01 使用者管理寄出帳號邀請並收信（第 2 項） |
| 教育訓練課程與學員 | 一門已發布、未關閉的課程，以及一位尚未加入該課程、測試者可收信的學員帳號（第 4 項）；以教師身分於 ET05 課程建立與編輯以 Email 邀請 |
| 範本原文紀錄 | 第 2、3 項會實際修改「帳號邀請」範本，測試前記下原文、測完改回 |

### 測試項目清單

| 項次 | 測試內容 |
|---|---|
