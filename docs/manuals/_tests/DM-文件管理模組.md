# 文件管理模組

## DM00 系統儀表板

### 測試前準備

| 項目 | 說明 |
|---|---|
| 編輯者 | 具編輯者角色者，例如示範編輯者（editor@edms.local），用於建立第 2～4 項之測試文件並查看主頁 |
| 審核者 | 具審核者角色者，例如示範審核者（reviewer@edms.local），用於核准下列送審與廢止申請 |
| 閱覽者甲 | **僅**具閱覽者角色、至少被授予可見對象「國防部軍醫局＋護理師」者，可沿用 DM01 之閱覽者甲，其另一組授權不影響本測試（第 5 項） |
| 測試文件 | 第 2 項需一份新建、分類為「其他」、可見對象為「國防部軍醫局＋護理師」的文件，送審後由審核者核准。第 3 項需一份已發布文件可上傳新版本。第 4 項需一份可廢止（核准後不可復原）之已發布文件提出廢止申請。上述文件若於測試當天才發布，請在其發布後才記錄第 2 項的起始數字 |

### 測試項目清單

| 項次 | 測試內容 |
|---|---|
| 1 | 以編輯者登入，主頁應出現「DM 文件概況」，上方為四類文件數與總計，下方為「最新更新公告」。 |
| 2 | 新文件經審核者核准發布後回主頁，該分類數字與總計應各加一，公告最上方出現該文件並標示「新增」加版本號。 |
| 3 | 既有文件之新版本核准發布後回主頁，分類數字與總計應不變，公告最上方出現該文件並標示「新版本」加版本號，該文件先前的公告列應不再出現。 |
| 4 | 對已發布文件提出廢止申請後，待審核期間該分類數字與總計應不變；審核者核准廢止後回主頁，該分類數字與總計應各減一，公告區該文件之列一併移除。 |
| 5 | 以閱覽者甲登入，公告中應有第 2 項之文件；「其他」之數字應等於閱覽者甲於 DM01 文件庫將分類選「其他」所得之筆數，且該清單中有第 2 項之文件；「訓練教材」之數字應為 0。 |
| 6 | 按公告中的任一列，應進入該文件之文件詳細頁；按「查看全部文件 →」應進入 DM01 文件庫。 |

## DM01 文件庫

### 測試前準備

| 項目 | 說明 |
|---|---|
| 編輯者甲 | 具編輯者角色，用於建立下列測試文件、驗證不受可見對象限制（第 7 項）與「新增文件」入口（第 20 項） |
| 編輯者乙 | 另一位具編輯者角色者，用於建立文件 I（第 10 項）與上傳文件 E 之新版本，驗證作者改為新版本上傳者（第 17 項） |
| 審核者 | 具審核者角色，用於核准下列文件之發布、新版本與廢止申請 |
| 閱覽者甲 | **僅**具閱覽者角色，被授予可見對象「國防部軍醫局＋護理師」與「國防醫學院三軍總醫院＋行政人員」兩組（第 2～5 項）；需由管理者於平台後台授予 |
| 閱覽者乙 | **僅**具閱覽者角色，**未被授予任何可見對象**（第 6 項） |
| 管理者 | 用於授予上述兩位閱覽者之角色與可見對象 |
| 文件 A | 已發布，分類「標準作業程序」，可見對象「全單位＋全體」，檢索標籤「採血」；首版摘要含一段文件名稱中沒有的詞（如「冷鏈溫度紀錄」），用於驗證關鍵字比對摘要（第 9 項） |
| 文件 B | 已發布，分類「其他」，可見對象「國防部軍醫局＋護理師」，檢索標籤「檢驗」 |
| 文件 C | 已發布，分類「標準作業程序」，可見對象「國防部軍醫局＋行政人員」——由閱覽者甲兩組授權之單位與職位交叉組成，用於驗證配對須整組相符（第 3 項） |
| 文件 D | 已發布，分類「系統操作手冊」，關聯作業項目選一個目前尚無已發布手冊之作業項目（每個作業項目只能有一份已發布手冊；可先於本作業將分類選「系統操作手冊」、作業項目選該項目，確認查無文件），可見對象「全單位＋全體」（第 16 項） |
| 文件 E | 已發布（**須於測試前一日（含）以前發布**，第 17 項才看得出發布日期更新），由編輯者甲建立，可見對象「全單位＋護理師」（第 2 項驗證「全單位」涵蓋任何單位）；測試中由編輯者乙上傳新版本並送審（第 17 項） |
| 文件 F | 已發布，可見對象「全單位＋全體」；測試中提出廢止申請，**核准後即不可復原**，請使用可廢止之文件（第 19 項） |
| 文件 G | 已發布，可見對象「國防醫學院三軍總醫院松山分院＋行政人員」，用於驗證單位不含其下分院（第 4 項） |
| 文件 H | 已發布，分類「訓練教材」（此分類不設可見對象），用於驗證閱覽者查不到訓練教材（第 5 項）與分類篩選（第 11 項） |
| 文件 I | 已發布，**由編輯者乙建立**，用於驗證作者篩選會排除他人之文件（第 10 項） |
| 草稿與送審中文件 | 首版存為草稿之文件一份、首版已送審尚未核准之文件一份（第 1 項） |
| 發布日期分散 | 上述文件中至少一份須於測試前一日（含）以前發布，否則驗不到日期區間篩選（第 14 項）；若環境中已有其他日期發布之文件，亦可直接使用 |

### 測試項目清單

| 項次 | 測試內容 |
|---|---|
| 1 | 以編輯者甲進入文件庫、不設任何條件，文件 A～I 皆應出現；測試前準備中首版為草稿或送審中之兩份文件不應出現。 |
| 2 | 以閱覽者甲登入，應看得到文件 A、文件 B、文件 E（可見對象開放全體、與本人授權整組相符，或以「全單位」涵蓋本人單位）。 |
| 3 | 以閱覽者甲登入，不應看到文件 C（「國防部軍醫局＋行政人員」雖由本人兩組授權之單位與職位交叉組成，但無一組整組相符）。 |
| 4 | 以閱覽者甲登入，不應看到文件 G（本人授權為國防醫學院三軍總醫院，不涵蓋其松山分院）。 |
| 5 | 以閱覽者甲登入，不應看到文件 H（訓練教材不設可見對象，僅具閱覽者角色者查不到）。 |
| 6 | 以閱覽者乙登入（須在第 19 項廢止文件 F 之前），應看得到可見對象為「全單位＋全體」之文件 A、D、F，文件 B、C、E、G、H 皆不應出現。 |
| 7 | 以編輯者甲登入，文件 B、C、G、H 皆應列出（具編輯者角色者不受可見對象限制，含訓練教材）。 |
| 8 | 於「關鍵字（文件名 / 摘要）」輸入文件 A 名稱的一段文字，不按任何按鈕，清單應自動篩出文件 A。 |
| 9 | 於「關鍵字（文件名 / 摘要）」輸入僅出現在文件 A 首版摘要中的詞，清單應列出文件 A。 |
| 10 | 於「作者（姓名）」輸入編輯者甲姓名中編輯者乙姓名沒有的一段文字，清單應只列出作者為編輯者甲的文件，文件 I 不應出現。 |
| 11 | 於「分類」選「訓練教材」，清單應只列出該分類之文件。 |
| 12 | 於「檢索標籤」同時選「採血」與「檢驗」，文件 A 與文件 B 皆應列出（掛有任一標籤即符合）。 |
| 13 | 關鍵字輸入文件 A 名稱並將分類改選「訓練教材」，清單應無文件 A（多個條件須同時符合）。 |
| 14 | 設定「發布日期 起」與「發布日期 迄」為同一天，清單應只列出該日發布之文件。 |
| 15 | 於「分類」選「系統操作手冊」，應出現「關聯作業項目（func_name）」下拉；選定作業項目後改選其他分類，該下拉應隱藏且作業項目條件一併清除。 |
| 16 | 分類選「系統操作手冊」、作業項目選文件 D 所設之作業項目，應只列出文件 D，且其文件名稱下方標示該作業項目（「代碼 — 名稱」）。 |
| 17 | 編輯者乙為文件 E 上傳新版本並送審，清單中文件 E 之發布日期應維持原值；審核者核准後發布日期更新為新版本之日期，作者改為編輯者乙（作者為目前發布版本的上傳者）。 |
| 18 | 點清單中任一列，應進入該文件之文件詳細頁。 |
| 19 | 對文件 F 提出廢止申請、尚未核准時，文件 F 應仍列於清單且可進入詳細頁；審核者核准廢止後，文件 F 應自清單移除。 |
| 20 | 以編輯者甲登入，搜尋結果右上方應有「新增文件」，按下後進入新增文件畫面；以閱覽者甲登入則不應出現「新增文件」。 |

## DM02 簽核中心

### 測試前準備

| 項目 | 說明 |
|---|---|
| 審核者甲（主要操作者） | 具審核者角色，本作業絕大多數項目以此帳號進行 |
| 審核者乙 | 另一位具審核者角色者，用於驗證清單只列指派給本人之項目（第 1 項） |
| 編輯者甲 | 具編輯者角色，負責下列各份文件之送審、廢止申請與撤回 |
| 閱覽者甲 | **僅**具閱覽者角色，被授予可見對象「國防部軍醫局＋護理師」，**須為可實際收信之信箱**（第 10 項） |
| 閱覽者乙 | **僅**具閱覽者角色，被授予可見對象「國防部軍醫局＋行政人員」，用於驗證可見對象不符者收不到發布通知、也查不到文件（第 10 項）；須為可實際收信之信箱，否則「收不到通知」無從確認 |
| 管理者 | 用於將催辦門檻調為 1 天（第 3、4 項，測完請改回原值，預設 7 天），以及查詢文件變更歷程（第 9、12 項） |
| 新增類送審 | 編輯者甲建立後指定審核者甲送審：文件 P（可見對象「國防部軍醫局＋護理師」，檢索標籤至少一個）、文件 Q（用於退回）；另一份指定**審核者乙**送審（第 1 項） |
| 新版本類送審 | 已發布文件 R 一份（**須於測試前一日（含）以前發布**，第 11 項才看得出發布日期更新），編輯者甲上傳新版本並指定審核者甲送審（第 6、11 項）；另一份已發布文件 S 同樣送新版本（第 14 項，用於退回） |
| 廢止類送審 | 已發布文件 T（**可見對象含「國防部軍醫局＋護理師」**，與閱覽者甲相同，第 12 項才驗得出不寄發布通知），編輯者甲提出廢止申請並**附廢止附件**（第 7、12 項，核准後不可復原）；已發布文件 U 提出廢止申請（第 15 項，用於退回） |
| 停留已滿 1 天之送審 | 指定審核者甲（**須為可實際收信之信箱**）、送審時間已超過 24 小時之項目**至少兩筆**，用於驗證紅字警示與催辦（第 3、4 項；第 4 項須有兩筆以上逾期，才驗得到「多筆仍只收一封」），請提前一天送審；另需一筆**當天才送審**（未滿 24 小時）之項目供第 3 項對照。催辦信的 N 為該審核者全部逾期筆數，可能含他人之送審 |
| 訓練教材送審 | 編輯者甲建立分類「訓練教材」之文件 AB，指定審核者甲送審（第 10-1 項） |
| 撤回用送審 | 指定審核者甲之送審兩筆，分別用於第 2 項與第 17 項 |
| 同作業項目之兩份手冊 | 編輯者甲建立兩份分類「系統操作手冊」、關聯作業項目相同之文件，皆指定審核者甲送審，且該作業項目**尚無已發布手冊**（第 18 項）。挑選作業項目前，先於 DM01 文件庫將分類選「系統操作手冊」、關聯作業項目選該項目，確認查無文件 |
| 兩個瀏覽器分頁 | 第 17 項需一邊以審核者甲開著簽核中心，另開一個分頁於該分頁以編輯者甲登入並撤回（各分頁之登入各自獨立） |

### 測試項目清單

| 項次 | 測試內容 |
|---|---|
| 1 | 以審核者甲進入簽核中心，「待簽核」不應出現指派給審核者乙之項目；再以審核者乙登入，該項目應出現在乙的「待簽核」。 |
| 2 | 編輯者甲於個人專區撤回一筆送審後，審核者甲重新進入簽核中心，該項目應已自「待簽核」消失，且不列於「已完成」。 |
| 3 | 管理者將催辦門檻調為 1 天後，送審已滿 24 小時之項目，其停留天數應以紅字加警示符號標示；未滿 24 小時者不標示。 |
| 4 | 承上，管理者於 DP06 排程作業總覽將「DM 簽核催辦」（SCHDM002）的執行時間（Cron）改為數分鐘後的時點（先抄下原值，預設 `0 8 * * *`），排程執行後審核者甲應收到一封催辦 Email，主旨為「【催辦】您有 N 件送審待簽核」，信中逐項列出其所有逾期送審之文件名稱與停留天數；有多筆逾期者仍只收到一封。測完將 Cron 改回原值。 |
| 5 | 點文件 P 之列，下方應展開簽核明細，顯示可見對象「國防部軍醫局＋護理師」、檢索標籤，以及「變更摘要」欄中撰寫者填寫之首版摘要，按「下載」可取得送審檔案。 |
| 6 | 點文件 R 之列（新版本），檔案區應並列目前發布版與待審新版，兩者皆可下載。 |
| 7 | 點文件 T 之列（廢止），變更摘要應顯示申請人填寫之廢止原因，且可「下載廢止附件」。 |
| 8 | 對文件 P 按「核准並發布」，於確認視窗按「確認核准」，應顯示「已核准並發布」，該項目移至「已完成」，文件 P 出現於文件庫（以審核者甲或編輯者甲查詢），編輯者甲之個人專區「我的文件動態」應出現該文件的「核准發布」列。 |
| 9 | 承上，管理者於文件變更歷程查詢應查得到文件 P 之發布紀錄，核准者為審核者甲。 |
| 10 | 承上，閱覽者甲應收到文件 P 之發布通知且於文件庫查得到文件 P；閱覽者乙應收不到通知、亦查不到文件 P。 |
| 10-1 | 對文件 AB（訓練教材）按「核准並發布」並「確認核准」，文件 AB 應轉為已發布（以審核者甲於文件庫查詢可見；訓練教材不設可見對象，閱覽者於文件庫查不到屬正常），閱覽者甲、閱覽者乙皆應收不到其發布通知。 |
| 11 | 核准文件 R 之新版本前，文件庫應仍為原發布版；核准後文件庫之發布日期更新為新版本，文件詳細頁之版本歷程中原版本標示為「已被取代」。 |
| 12 | 對文件 T 按「核准並廢止」並「確認廢止」，文件 T 應自文件庫下架，編輯者甲之「我的文件動態」應出現「已廢止」列（站內呈現，不寄 Email），且不寄出文件發布通知；文件變更歷程查詢應留有其廢止紀錄。 |
| 13 | 對文件 Q 按「退回」，填寫退回原因後按「確認退回」，該項目應標示為已退回並移至「已完成」，文件 Q 回到編輯者甲個人專區之「草稿匣」（草稿類型「被退回待修改」）；編輯者甲之「我的文件動態」應出現「已退回」列（站內呈現，不寄 Email），該列「退回原因」欄顯示剛才填寫的退回原因全文。 |
| 14 | 退回文件 S 之新版本後，文件庫中文件 S 應仍為原發布版，新版本回到編輯者甲之「草稿匣」（被退回待修改）。 |
| 15 | 退回文件 U 之廢止申請後，文件 U 應仍為已發布並照常列於文件庫；編輯者甲之「我的文件動態」該筆「已退回」列的「退回原因」欄應顯示所填原因。 |
| 16 | 切換至「已完成」，應列出本人核准與退回之項目、結果與送審者；文件 Q 之退回列「退回原因」欄應為所填原因，文件 P 之核准列為「—」；於「搜尋文件名稱」輸入文件 P 名稱之一段應篩出該筆，且項目上無核准或退回之操作。 |
| 17 | 審核者甲開啟某送審之簽核明細後，編輯者甲於另一分頁撤回該送審，審核者甲再按「核准並發布」應被擋下並提示已被撰寫者撤回，該項目自清單移除。 |
| 18 | 兩份同作業項目之手冊送審中，核准其中一份後再核准另一份，應被擋下並提示該作業項目已有已發布手冊（未擋下將出現兩份手冊，依作業項目查詢結果不再唯一）。測完請將第二份退回或由編輯者甲撤回。 |

## DM03 已廢止文件查詢

### 測試前準備
