# 文件管理模組

## DM01 文件庫

### 測試前準備

| 項目 | 說明 |
|---|---|
| 編輯者甲 | 具編輯者角色，用於建立下列測試文件、驗證不受可見對象限制（第 7 項）與「新增文件」入口（第 20 項） |
| 編輯者乙 | 另一位具編輯者角色者，用於上傳文件 E 之新版本，驗證作者仍為建立者（第 17 項） |
| 審核者 | 具審核者角色，用於核准下列文件之發布、新版本與廢止申請 |
| 閱覽者甲 | **僅**具閱覽者角色，被授予可見對象「國防部軍醫局＋護理師」與「國防醫學院三軍總醫院＋行政人員」兩組（第 2～5 項）；需由管理者於平台後台授予 |
| 閱覽者乙 | **僅**具閱覽者角色，**未被授予任何可見對象**（第 6 項） |
| 管理者 | 用於授予上述兩位閱覽者之角色與可見對象 |
| 文件 A | 已發布，分類「標準作業程序」，可見對象「全單位＋全體」，檢索標籤「採血」；首版摘要含一段文件名稱中沒有的詞（如「冷鏈溫度紀錄」），用於驗證關鍵字比對摘要（第 9 項） |
| 文件 B | 已發布，分類「其他」，可見對象「國防部軍醫局＋護理師」，檢索標籤「檢驗」 |
| 文件 C | 已發布，分類「標準作業程序」，可見對象「國防部軍醫局＋行政人員」——由閱覽者甲兩組授權之單位與職位交叉組成，用於驗證配對須整組相符（第 3 項） |
| 文件 D | 已發布，分類「系統操作手冊」，關聯作業項目「BC01 捐血登錄」，可見對象「全單位＋全體」（第 16 項） |
| 文件 E | 已發布，由編輯者甲建立，可見對象「全單位＋護理師」（第 2 項驗證「全單位」涵蓋任何單位）；測試中由編輯者乙上傳新版本並送審（第 17 項） |
| 文件 F | 已發布，可見對象「全單位＋全體」；測試中提出廢止申請，**核准後即不可復原**，請使用可廢止之文件（第 19 項） |
| 文件 G | 已發布，可見對象「國防醫學院三軍總醫院松山分院＋行政人員」，用於驗證單位不含其下分院（第 4 項） |
| 文件 H | 已發布，分類「訓練教材」（此分類不設可見對象），用於驗證閱覽者查不到訓練教材（第 5 項）與分類篩選（第 11 項） |
| 草稿與送審中文件 | 首版存為草稿之文件一份、首版已送審尚未核准之文件一份（第 1 項） |
| 發布日期分散 | 上述文件中至少兩份之發布日期不同日，否則驗不到日期區間篩選（第 14 項） |

### 測試項目清單

| 項次 | 測試內容 |
|---|---|
| 1 | 以編輯者甲進入文件庫、不設任何條件，應列出全部已發布文件；首版為草稿或送審中之文件不應出現。 |
| 2 | 以閱覽者甲登入，應看得到文件 A、文件 B、文件 E（可見對象開放全體、與本人授權整組相符，或以「全單位」涵蓋本人單位）。 |
| 3 | 以閱覽者甲登入，不應看到文件 C（「國防部軍醫局＋行政人員」雖由本人兩組授權之單位與職位交叉組成，但無一組整組相符）。 |
| 4 | 以閱覽者甲登入，不應看到文件 G（本人授權為國防醫學院三軍總醫院，不涵蓋其松山分院）。 |
| 5 | 以閱覽者甲登入，不應看到文件 H（訓練教材不設可見對象，僅具閱覽者角色者查不到）。 |
| 6 | 以閱覽者乙登入，應只看得到可見對象為「全單位＋全體」之文件，文件 B、C、E、G、H 皆不應出現。 |
| 7 | 以編輯者甲登入，文件 B、C、G、H 皆應列出（具編輯者角色者不受可見對象限制，含訓練教材）。 |
| 8 | 於「關鍵字（文件名 / 摘要）」輸入文件 A 名稱的一段文字，不按任何按鈕，清單應自動篩出文件 A。 |
| 9 | 於「關鍵字（文件名 / 摘要）」輸入僅出現在文件 A 首版摘要中的詞，清單應列出文件 A。 |
| 10 | 於「作者（姓名）」輸入編輯者甲姓名的一段文字，清單應只列出編輯者甲建立的文件。 |
| 11 | 於「分類」選「訓練教材」，清單應只列出該分類之文件。 |
| 12 | 於「檢索標籤」同時選「採血」與「檢驗」，文件 A 與文件 B 皆應列出（掛有任一標籤即符合）。 |
| 13 | 關鍵字輸入文件 A 名稱並將分類改選「訓練教材」，清單應無文件 A（多個條件須同時符合）。 |
| 14 | 設定「發布日期 起」與「發布日期 迄」為同一天，清單應只列出該日發布之文件。 |
| 15 | 於「分類」選「系統操作手冊」，應出現「關聯作業項目（func_name）」下拉；選定作業項目後改選其他分類，該下拉應隱藏且作業項目條件一併清除。 |
| 16 | 分類選「系統操作手冊」、作業項目選「BC01 — 捐血登錄」，應只列出文件 D，且其文件名稱下方標示所對應之作業項目。 |
| 17 | 編輯者乙為文件 E 上傳新版本並送審，清單中文件 E 之發布日期應維持原值；審核者核准後發布日期更新為新版本之日期，作者仍為編輯者甲。 |
| 18 | 點清單中任一列，應進入該文件之文件詳細頁。 |
| 19 | 對文件 F 提出廢止申請、尚未核准時，文件 F 應仍列於清單且可進入詳細頁；審核者核准廢止後，文件 F 應自清單移除。 |
| 20 | 以編輯者甲登入，搜尋結果右上方應有「新增文件」，按下後進入新增文件畫面；以閱覽者甲登入則不應出現「新增文件」。 |

## DM02 簽核中心

### 測試前準備

| 項目 | 說明 |
|---|---|
| 審核者甲（主要操作者） | 具審核者角色，本作業絕大多數項目以此帳號進行 |
| 審核者乙 | 另一位具審核者角色者，用於驗證清單只列指派給本人之項目（第 1 項） |
| 編輯者甲 | 具編輯者角色，負責下列各份文件之送審、廢止申請與撤回 |
| 閱覽者甲 | **僅**具閱覽者角色，被授予可見對象「國防部軍醫局＋護理師」（第 10 項） |
| 閱覽者乙 | **僅**具閱覽者角色，被授予可見對象「國防部軍醫局＋行政人員」，用於驗證可見對象不符者收不到發布通知、也查不到文件（第 10 項） |
| 管理者 | 用於將催辦門檻調為 1 天（第 3、4 項，測完請改回原值，預設 7 天），以及查詢文件變更歷程（第 9、12 項） |
| 新增類送審 | 編輯者甲建立後指定審核者甲送審：文件 P（可見對象「國防部軍醫局＋護理師」，檢索標籤至少一個）、文件 Q（用於退回）；另一份指定**審核者乙**送審（第 1 項） |
| 新版本類送審 | 已發布文件 R 一份，編輯者甲上傳新版本並指定審核者甲送審（第 6、11 項）；另一份已發布文件 S 同樣送新版本（第 14 項，用於退回） |
| 廢止類送審 | 已發布文件 T，編輯者甲提出廢止申請並**附廢止附件**（第 7、12 項，核准後不可復原）；已發布文件 U 提出廢止申請（第 15 項，用於退回） |
| 停留已滿 1 天之送審 | 至少一筆送審時間已超過 24 小時之項目，用於驗證紅字警示與催辦（第 3、4 項）；請提前一天送審 |
| 撤回用送審 | 指定審核者甲之送審兩筆，分別用於第 2 項與第 17 項 |
| 同作業項目之兩份手冊 | 編輯者甲建立兩份分類「系統操作手冊」、關聯作業項目相同（如「BC02 健康問卷填寫」）之文件，皆指定審核者甲送審，且該作業項目**尚無已發布手冊**（第 18 項） |
| 兩個瀏覽器分頁 | 第 17 項需一邊以審核者甲開著簽核中心、一邊以編輯者甲撤回 |

### 測試項目清單

| 項次 | 測試內容 |
|---|---|
| 1 | 以審核者甲進入簽核中心，「待簽核」應只列出指定審核者為本人之送審，指派給審核者乙之項目不應出現。 |
| 2 | 編輯者甲於個人專區撤回一筆送審後，審核者甲重新進入簽核中心，該項目應已自「待簽核」消失，且不列於「已完成」。 |
| 3 | 管理者將催辦門檻調為 1 天後，送審已滿 24 小時之項目，其停留天數應以紅字加警示符號標示；未滿 24 小時者不標示。 |
| 4 | 承上，每日催辦排程執行後（或請 IT 手動觸發），審核者甲應收到該項目之催辦通知。 |
| 5 | 點文件 P 之列，下方應展開簽核明細，顯示可見對象「國防部軍醫局＋護理師」、檢索標籤與首版摘要，按「下載」可取得送審檔案。 |
| 6 | 點文件 R 之列（新版本），檔案區應並列目前發布版與待審新版，兩者皆可下載。 |
| 7 | 點文件 T 之列（廢止），變更摘要應顯示申請人填寫之廢止原因，且可「下載廢止附件」。 |
| 8 | 對文件 P 按「核准並發布」，於確認視窗按「確認核准」，應顯示「已核准並發布，已通知撰寫者」，該項目移至「已完成」，文件 P 出現於文件庫，編輯者甲收到文件發布通知。 |
| 9 | 承上，管理者於文件變更歷程查詢應查得到文件 P 之發布紀錄，核准者為審核者甲。 |
| 10 | 承上，閱覽者甲應收到文件 P 之發布通知且於文件庫查得到文件 P；閱覽者乙應收不到通知、亦查不到文件 P。 |
| 11 | 核准文件 R 之新版本前，文件庫應仍為原發布版；核准後文件庫之發布日期更新為新版本，文件詳細頁之版本歷程中原版本標示為「已被取代」。 |
| 12 | 對文件 T 按「核准並廢止」並「確認廢止」，文件 T 應自文件庫下架，編輯者甲收到通知，且不寄出文件發布通知；文件變更歷程查詢應留有其廢止紀錄。 |
| 13 | 對文件 Q 按「退回」，填寫退回原因後按「確認退回」，該項目應標示為已退回並移至「已完成」，文件 Q 回到編輯者甲個人專區之草稿，編輯者甲收到退回通知。 |
| 14 | 退回文件 S 之新版本後，文件庫中文件 S 應仍為原發布版，新版本回到編輯者甲之草稿。 |
| 15 | 退回文件 U 之廢止申請後，文件 U 應仍為已發布並照常列於文件庫。 |
| 16 | 切換至「已完成」，應列出本人核准與退回之項目及其結果；於「搜尋文件名稱」輸入文件 P 名稱之一段應篩出該筆，且項目上無核准或退回之操作。 |
| 17 | 審核者甲開啟某送審之簽核明細後，編輯者甲於另一分頁撤回該送審，審核者甲再按「核准並發布」應被擋下並提示已被撰寫者撤回，該項目自清單移除。 |
| 18 | 兩份同作業項目之手冊送審中，核准其中一份後再核准另一份，應被擋下並提示該作業項目已有已發布手冊（未擋下將出現兩份手冊，依作業項目查詢結果不再唯一）。 |

## DM03 已廢止文件查詢

### 測試前準備

| 項目 | 說明 |
|---|---|
| 管理者 | 具文件管理管理者角色，本作業全部項目以此帳號進行 |
| 編輯者甲、編輯者乙 | 具編輯者角色，用於建立下列文件並提出廢止申請；編輯者乙用於上傳文件 W 的新版本（第 6 項） |
| 審核者 | 具審核者角色，用於核准下列文件之發布與廢止 |
| 文件 V | 已廢止，分類「標準作業程序」，PDF 檔，申請廢止時**附有廢止附件**，廢止原因含一段文件名稱中沒有的詞（如「併入新版規範」）（第 2、8、9 項） |
| 文件 W | 已廢止，分類「其他」，由編輯者甲建立 v1.0、編輯者乙上傳 v1.1 後才廢止，用於驗證原作者為末版撰寫者（第 6 項）；v1.1 為 **Word 檔**，用於驗證無法預覽的版本可下載（第 10 項） |
| 廢止日期分散 | 文件 V、W 於不同日核准廢止，否則驗不到日期區間篩選（第 5 項）；請提前一天核准其中一份 |
| 廢止簽核中之文件 | 已提出廢止申請、**尚未核准**之文件 X 一份（第 12 項） |

### 測試項目清單

| 項次 | 測試內容 |
|---|---|
| 1 | 以管理者進入已廢止文件查詢、不設任何條件，應列出全部已廢止文件；已發布中的文件不應出現。 |
| 2 | 於「關鍵字（文件名 / 廢止原因）」輸入僅出現在文件 V 廢止原因中的詞，不按任何按鈕，清單應自動篩出文件 V。 |
| 3 | 於「關鍵字（文件名 / 廢止原因）」輸入文件 W 名稱的一段文字，清單應列出文件 W。 |
| 4 | 於「分類」選「其他」，清單應只列出文件 W 等該分類之已廢止文件。 |
| 5 | 將「廢止日期 起」與「廢止日期 迄」設為文件 V 核准廢止的同一天，清單應只列出文件 V。 |
| 6 | 查看文件 W 該列，「原作者」應為上傳末版的編輯者乙，文件名稱下方應標示版本 v1.1。 |
| 7 | 點文件 V 之列，應進入唯讀頁面，上方紅色提示列顯示廢止時間、申請人、核准者與廢止原因，頁面上無編輯新版本、廢止等操作按鈕。 |
| 8 | 承上，按「下載廢止附件」應取得申請廢止時附上的檔案。 |
| 9 | 承上，版本歷程應自動展開，各版本可按「預覽」檢視，PDF 版本不提供下載；按標題左側的返回箭頭應回到查詢清單。 |
| 10 | 進入文件 W 的唯讀頁面，Word 檔的 v1.1 應提供「下載」，可取得原檔。 |
| 11 | 按「匯出 CSV」，下載的檔案以 Excel 開啟中文正常，內容為目前查詢條件下的全部結果，廢止時間與畫面一致。 |
| 12 | 文件 X 之廢止申請尚未核准時，不應出現於本作業；審核者核准後，文件 X 應出現於清單且自文件庫下架。 |

## DM04 個人專區

### 測試前準備

| 項目 | 說明 |
|---|---|
| 編輯者甲 | 具編輯者角色、不兼審核者，下列文件皆由此帳號建立與送審 |
| 雙角色帳號 | 同時具編輯者與審核者角色之帳號，近 30 天內本人送審過、也被指派審核過至少各一筆（第 1 項） |
| 審核者甲、審核者乙 | 具審核者角色。審核者乙用於帳號停用（第 4 項）與改選審核者（第 8 項） |
| 管理者 | 將催辦門檻調為 1 天（第 3 項，測完請改回預設 7 天）；於 DP01 使用者管理停用審核者乙，第 4 項測完即重新啟用 |
| 文件 A | 近 30 天內送審、經審核者甲核准發布（第 2 項） |
| 文件 B | 指定審核者乙之送審，未處理（第 4 項） |
| 文件 C | 指定審核者甲之送審，送審已超過 24 小時且未處理（第 3 項）；請提前一天送審 |
| 文件 D | 新增類送審，指定審核者甲、未處理（第 5、6、8 項） |
| 文件 E | 已發布文件之廢止申請，指定審核者甲、未處理（第 7 項） |
| 文件 F | 送審後經審核者甲退回（第 10 項） |
| 文件 G | 已發布文件，編輯者甲另存一份新版本草稿、未送審（第 10、11 項） |
| 文件 H | 編輯者甲存有新版本草稿後，該文件由他人申請廢止並經核准（第 12 項） |

### 測試項目清單

| 項次 | 測試內容 |
|---|---|
| 1 | 以雙角色帳號進入個人專區，「我的文件動態」應同時出現「撰寫者視角（近 30 天）」與「審核者視角（近 30 天）」兩區。 |
| 2 | 以編輯者甲進入個人專區，文件 A 應呈現「送審」與「核准發布」兩列，時間分別為送審與核准時間，清單由新到舊排列。 |
