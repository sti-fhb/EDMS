# 教育訓練文件管理模組

## ET01 課程列表

### 測試前準備

| 項目 | 說明 |
|---|---|
| 教師甲（主要操作者） | 具教師角色。名下需有草稿、已發布、已關閉課程各至少 1 門——驗證「我建立的」列出全部狀態（第 1 項），並與教師乙的視角對照（第 2 項） |
| 教師乙 | 另一位具教師角色者。名下需有已發布課程至少 2 門、草稿 1 門、已關閉 1 門——其中 1 門已發布課程供教師甲加入（第 3 項），加入後即不出現在教師甲的「全部課程」，故需另有 1 門未加入者用於第 2、4 項；草稿與已關閉者用於驗證不出現在教師甲的「全部課程」（第 2 項） |
| 教師甲已加入的他人課程 | 教師甲以學員身分（「我的課程 → 加入新課程」輸入邀請碼）加入教師乙的一門已發布課程——驗證該課程不出現在教師甲的「全部課程」（第 3 項）；沒有加入過的課程驗不到 |
| 管理者丙 | 具教育訓練管理者角色、**不具教師角色**——用於驗證只剩「全部課程」（第 13 項）；兼具教師角色者驗不到 |
| 學員二位 | 已在教師甲某門已發布課程中，其中一位用於在 ET02 移出課程（第 7 項） |
| 受訓對象組合 | 已發布、閱課期間進行中、教師甲未以學員身分加入的課程中，需分別有下列受訓對象，用於在「全部課程」驗證字面比對（第 9、10 項）：<br>A 課程「全單位 + 護理師」<br>B 課程「松山分院 + 護理師」<br>C 課程「松山分院 + 全體」<br>D 課程「松山分院 + 行政」與「全單位 + 護理師」兩組<br>單位、職位名稱可依現有清單替換，關係需相同 |
| 已停用的受訓對象值 | 一門課程的受訓對象使用某單位或職位，之後該值由管理者於 DP03 停用——驗證停用值仍可篩選（第 11 項） |
| 可調整訖止時間的已發布課程 | 教師甲名下一門已發布、閱課期間進行中的課程，測試中會把訖止時間改到已過去的時點（第 6 項）；改完後該課程即對學員關閉，請用專供測試的課程 |

### 測試項目清單

| 項次 | 測試內容 |
|---|---|
| 1 | 以教師甲於「我建立的」檢視，應列出本人的草稿、已發布、已關閉課程，且不含任何其他教師的課程。 |
| 2 | 以教師甲切到「全部課程」，應列出教師乙的已發布課程，教師乙的草稿與已關閉課程皆不出現。 |
| 3 | 教師甲以學員身分已加入的教師乙課程，不應出現在教師甲的「全部課程」。 |
| 4 | 以教師甲於「全部課程」點教師乙的課程（卡片標「檢視」），應以學員視角開啟並標示「預覽模式」，不記錄學習進度。 |
| 5 | 以教師甲於「我建立的」點本人課程，應進入可編輯的 ET05 編輯頁；於「全部課程」點同一門本人的已發布課程，則進入預覽頁。 |
| 6 | 將教師甲某門已發布課程的訖止時間改為已過去的時點並按「更新」，回到「我建立的」該卡片應標示「已關閉」，且該課程不再出現於教師乙的「全部課程」。 |
| 7 | 於 ET02 將某位學員移出教師甲的課程後回到課程列表，該課程卡片的學員人數應減少一位。 |
| 8 | 於「關鍵字」輸入課程名稱中間的一段文字，清單應隨即只列出名稱含該段文字的課程。 |
| 9 | 於「全部課程」職位選「護理師」、單位選「不限」，應列出 A、B、D 課程，不列出 C 課程（「松山分院 + 全體」）。 |
| 10 | 於「全部課程」單位選「松山分院」、職位選「護理師」，應列出 B 課程，不列出 D 課程（兩組各符合一欄）。 |
| 11 | 於單位或職位下拉選標示「（已停用）」的值，應列出受訓對象使用該值的課程。 |
| 12 | 於「全部課程」以「建立者」選教師乙，清單應只剩教師乙的課程；切回「我建立的」後建立者欄位不再顯示。 |
| 13 | 以管理者丙登入進入課程列表，應只有「全部課程」清單、沒有「我建立的」與「新增課程」，點任一卡片皆以預覽開啟。 |
| 14 | 以教師甲按「新增課程」，應進入 ET05 的新增課程畫面。 |

## ET02 學員

### 測試前準備

| 項目 | 說明 |
|---|---|
| 教師甲（主要操作者） | 具教師角色，下列課程甲、乙、丙、丁皆由此帳號建立；本作業全部項目以此帳號操作 |
| 教師乙 | 另一位具教師角色者，自行建立並發布一門課程，用於驗證他人的課程不出現在教師甲的下拉中（第 1 項） |
| 管理者 | 用於至 DP05 操作記錄查詢確認匯出紀錄（第 9 項） |
| 課程甲（主要受測課程） | 已發布、閱課期間進行中、**已開啟「本課程需線下核可」**、設有課後問卷（至少 1 題單選與 1 題問答）。至少 2 份測驗，其中「測驗一」的重考次數上限設為 1（共可作答 2 次），方便讓學員用盡次數 |
| 課程乙 | 已發布、**未開啟**線下核可、**未建立**課後問卷，至少 1 位學員；用於驗證核可欄與問卷區塊隱藏、CSV 核可欄填「—」（第 8、24、28 項） |
| 課程丙 | 已關閉（按「關閉課程」即可），至少 1 位學員已有作答紀錄；用於驗證唯讀（第 2 項） |
| 課程丁 | 教師甲的草稿課程一門；用於驗證草稿不出現在下拉中（第 1 項） |
| 課程戊 | 教師甲已發布、設有課後問卷、**尚無任何學員**的課程一門（例如受訓對象設為無人符合之組合）；用於驗證兩顆「匯出 CSV」皆呈灰色（第 8-1 項） |
| 學員 A | 於課程甲**已完課**，且已填寫課後問卷；用於逐一核可通過與通知信（第 30、33、34 項）。需能收信 |
| 學員 B | 於課程甲**已完課**；用於核可不通過（第 31 項） |
| 學員 C、D | 於課程甲**已完課**且尚未核可；用於批次核可（第 35 項）。需能收信 |
| 學員 L | 於課程甲**已完課**且尚未核可；用於兩個分頁的核可（第 37 項） |
| 學員 A～D、L 於核可前補完課程 | 第 6 項新增教材、第 22 項要求重測「測驗一」後，上述已完課學員皆回到「進行中」，核可欄顯示「未達核可資格」、沒有核可按鈕。**第 29 項開始前**，請學員 A～D 與 L 補完第 6 項新增的教材，並重新作答「測驗一」至及格，使其回到「已完成」；第 37 項開始前，學員 L 另須補完第 36 項新增的教材 |
| 學員 E | 已加入課程甲但**尚未開始任何學習**；用於驗證平均成績「—」與「未達核可資格」（第 3、29 項） |
| 學員 F | 於課程甲「測驗一」作答且**全部答錯得 0 分**；用於驗證平均成績顯示 0 而非「—」（第 3 項） |
| 學員 G | 於課程甲「測驗一」**已作答 2 次（次數用盡）、兩次分數不同且皆未及格**，「測驗二」未作答；用於平均成績只計已作答測驗並取最高分（第 4 項）與重置重考次數（第 15、20、21 項）。沒有用盡次數的學員重置鈕不會亮。第 4 項請在第 20 項之前做 |
| 學員 H | 於課程甲「測驗一」只作答 1 次且未及格（尚有 1 次）、「測驗二」未作答；用於驗證重置鈕停用與「尚未作答」（第 14、19 項） |
| 學員 K | 於課程甲「測驗一」**已及格**、「測驗二」**未作答**（第 22-1 項的平均成績才只反映「測驗一」）；用於驗證已及格者重置鈕停用（第 19 項），及「儲存並要求重測」後重測未及格的情境（第 22 項：學員 K 須於要求重測後再作答 2 次皆不及格） |
| 學員 I | 已加入課程甲、**尚未填寫課後問卷**（移除後未填人數才會減少，第 10 項），用於移除與重新邀請（第 10～12 項）；須知道課程甲的邀請碼 |
| 學員 J | 已加入課程甲，**於測試當下開始作答某份測驗但先不要交卷**；用於移除作答中學員（第 13 項）。請在第 13 項開始前讓學員 J 開始作答 |
| 兩個瀏覽器分頁 | 以教師甲同時開啟本頁並選定課程甲，用於驗證核可不被覆寫（第 37 項）。切回某個分頁時清單會自動重新載入，故須先於分頁二開好確認視窗、再到分頁一核可 |

### 測試項目清單

| 項次 | 測試內容 |
|---|---|
| 1 | 以教師甲進入「學員學習表現」，「課程」下拉應只列出教師甲建立的已發布與已關閉課程，不含課程丁（草稿）與教師乙的課程。 |
| 2 | 選擇課程丙（已關閉），應顯示唯讀提示；三區塊照常顯示，「移除」「重置重考次數」皆呈灰色，「匯出 CSV」仍可匯出。 |

| 輔助課程 | 另一門已發布、閱課期間進行中的課程，學員甲、學員乙皆已加入；**第 1 章依序為測驗 C、測驗 B，其後至少 1 份教材**（課程須有教材才能發布）。章節內依序解鎖：測驗 C 排第一，加入後即可點開；測驗 B 須於測驗 C 通過後才開放，故**學員甲須先作答測驗 C 至及格** |
| 測驗 B（不限時） | 輔助課程中的測驗，作答時間限制**留空**、重考次數上限 **0**（只能作答 1 次），由學員甲作答，用於第 2、3 項 |
| 測驗 C（次數用盡用） | 輔助課程中的測驗，學員乙作答用，重考次數上限 **1**（可作答 2 次）。第 22 項前請學員乙先以低於及格分數交卷 2 次 |
| 關閉用課程 | 另一門已發布、閱課期間進行中的課程，含一份測驗，學員丙已加入並已可點開該測驗。學員丙先交卷 1 次（第 26 項才有歷次紀錄可點閱），接著**再開始一次作答但不交卷**，然後由教師甲關閉課程。第 25 項須等系統每日排程（台灣時間每日 08:00）執行後確認 |
| 保留未交卷的作答 | 作答中切換視窗、關閉分頁或重新整理都會觸發自動提交，該次即不再是未交卷。第 10 項與「關閉用課程」需要一次未交卷的作答時，請於作答畫面以工作管理員直接結束瀏覽器程式；第 10 項的測驗 A 限時 3 分鐘，請於時限內重新登入並完成該項 |
| 瀏覽器 | 測試期間關閉會跳出系統通知的程式；第 8 項需可另開一個分頁 |

### 測試項目清單

| 項次 | 測試內容 |
|---|---|
| 1 | 學員甲於課程學習頁點測驗 A，內容區應直接顯示題數、作答時間、及格分數與剩餘可作答次數，不另開新畫面。 |
| 2 | 學員甲開啟測驗 B，作答時間應顯示「不限時」；開始作答後作答畫面不顯示剩餘時間，停留超過數分鐘亦不會自動提交。 |
| 3 | 測驗 B 的重考次數上限為 0，作答前剩餘可作答應為 1 次；交卷 1 次後應變為 0 次且「開始作答」不可按。 |
| 4 | 測驗 A 作答前剩餘可作答應為 20 次；按「開始作答」後回到測驗項目，剩餘可作答應已減為 19 次。 |
| 5 | 於作答畫面點左側任一題號應跳至該題；作答後該題號改為已答標示，「已答 N / 5」隨之增加。 |
| 6 | 作答中點左側選單「我的課程」，應跳出「離開作答」確認視窗；按「繼續作答」應留在作答畫面，已作答的內容不變。 |
| 7 | 承上，再點左側選單並於確認視窗按「提交並離開」，應顯示「已提交本次作答」並前往「我的課程」；回到測驗 A，歷次作答紀錄應出現該次成績，且不再有可接續的作答。 |
| 8 | 作答中切換到另一個瀏覽器分頁，本次作答應立即自動提交，回到原分頁時為結果頁，上方顯示「因離開作答視窗，本次作答已自動提交。」，且計入一次作答次數。 |
| 9 | 開始作答後作答 2 題並等倒數歸零，系統應自動提交，結果頁顯示「作答時間到，已自動提交」，該 2 題照常計分；歷次作答紀錄中該次標示「逾時」。 |
| 10 | 開始作答、切換題目暫存 1 題後，以工作管理員直接結束瀏覽器程式；重新開啟瀏覽器登入並進入測驗 A，測驗項目應提示「您上次的作答尚未提交…」；按「開始作答」，結果頁上方應顯示「您上次的作答未提交，已以暫存的作答自動提交。」，成績為以已暫存的那 1 題計分。 |
| 11 | 學員甲作答中，教師甲將測驗 A 某題的正確答案改掉並儲存題目，再按「更新」；學員甲依原題目作答並提交，該題應依開始作答當時的正確答案計分。 |
| 12 | 作答到最後一題選好答案後不切換題目，直接按「提交」，應立即交卷（不另跳確認視窗），且該題作答計入成績。 |
| 13 | 留 1 題完全不作答就按「提交」，該題於答題明細應顯示「未作答」、得 0 分。 |
| 14 | 單選題選對應得該題全部配分，選錯應得 0 分。 |
| 15 | 測驗 A 的多選題（配分 30、3 個正確選項）選 2 個正確、1 個錯誤，該題應得 10 分並標示「部分對」；選 1 個正確、2 個錯誤應得 0 分，且不扣其他題的分數。 |
| 16 | 結果頁答題明細應列出每題的正確答案；點任一列開啟「題目檢討」，選項應逐一標示答對、選錯或漏選。 |
| 17 | 重新作答時，題目與選項的排列順序應與前一次不同；同一次作答中切換題目來回，順序則維持不變。 |
| 18 | 測驗 A 總分達 80 分以上，結果頁應顯示合格；回到課程學習頁，該測驗項目標示完成，下一章隨即可點開。 |
| 19 | 測驗 A 未達及格分數且仍有次數，結果頁應顯示「未達及格分數，您仍有重考機會」與「回課程重新作答」；按下應回到課程學習頁並停在測驗 A，不直接開始新的作答。 |
