# 教育訓練文件管理模組

## ET01 課程列表

### 測試前準備

| 項目 | 說明 |
|---|---|
| 教師甲（主要操作者） | 具教師角色。名下需有草稿、已發布、已關閉課程各至少 1 門——驗證「我建立的」列出全部狀態（第 1 項），並與教師乙的視角對照（第 2 項） |
| 教師乙 | 另一位具教師角色者。名下需有已發布課程至少 1 門、草稿 1 門、已關閉 1 門——草稿與已關閉者用於驗證不出現在教師甲的「全部課程」（第 2 項） |
| 教師甲已加入的他人課程 | 教師甲以學員身分（「我的課程 → 加入新課程」輸入邀請碼）加入教師乙的一門已發布課程——驗證該課程不出現在教師甲的「全部課程」（第 3 項）；沒有加入過的課程驗不到 |
| 管理者丙 | 具教育訓練管理者角色、**不具教師角色**——用於驗證只剩「全部課程」（第 13 項）；兼具教師角色者驗不到 |
| 學員二位 | 已在教師甲某門已發布課程中，其中一位用於在 ET02 移出課程（第 7 項） |
| 受訓對象組合 | 已發布課程中需分別有下列受訓對象，用於驗證字面比對（第 9、10 項）：<br>A 課程「全單位 + 護理師」<br>B 課程「松山分院 + 護理師」<br>C 課程「松山分院 + 全體」<br>D 課程「松山分院 + 行政」與「全單位 + 護理師」兩組<br>單位、職位名稱可依現有清單替換，關係需相同 |
| 已停用的受訓對象值 | 一門課程的受訓對象使用某單位或職位，之後該值由管理者於 DP03 停用——驗證停用值仍可篩選（第 11 項） |
| 可調整訖止時間的已發布課程 | 教師甲名下一門已發布、閱課期間進行中的課程，測試中會把訖止時間改到已過去的時點（第 6 項）；改完後該課程即對學員關閉，請用專供測試的課程 |

### 測試項目清單

| 項次 | 測試內容 |
|---|---|
| 1 | 以教師甲於「我建立的」檢視，應列出本人的草稿、已發布、已關閉課程，且不含任何其他教師的課程。 |
| 2 | 以教師甲切到「全部課程」，應列出教師乙的已發布課程，教師乙的草稿與已關閉課程皆不出現。 |
| 3 | 教師甲以學員身分已加入的教師乙課程，不應出現在教師甲的「全部課程」。 |
| 4 | 以教師甲於「全部課程」點教師乙的課程（卡片標「檢視」），應以學員視角開啟並標示「預覽模式」，不記錄學習進度。 |
| 5 | 以教師甲於「我建立的」點本人課程，應進入可編輯的 ET05 編輯頁；於「全部課程」點同一門本人的已發布課程，則進入預覽頁。 |
| 6 | 將教師甲某門已發布課程的訖止時間改為已過去的時點並儲存，回到「我建立的」該卡片應標示「已關閉」，且該課程不再出現於教師乙的「全部課程」。 |
| 7 | 於 ET02 將某位學員移出教師甲的課程後回到課程列表，該課程卡片的學員人數應減少一位。 |
| 8 | 於「關鍵字」輸入課程名稱中間的一段文字，清單應隨即只列出名稱含該段文字的課程。 |
| 9 | 職位選「護理師」、單位選「不限」，應列出 A、B、D 課程，不列出 C 課程（「松山分院 + 全體」）。 |
| 10 | 單位選「松山分院」、職位選「護理師」，應只列出 B 課程，D 課程（兩組各符合一欄）不應列出。 |
| 11 | 於單位或職位下拉選標示「（已停用）」的值，應列出受訓對象使用該值的課程。 |
| 12 | 於「全部課程」以「建立者」選教師乙，清單應只剩教師乙的課程；切回「我建立的」後建立者欄位不再顯示。 |
| 13 | 以管理者丙登入進入課程列表，應只有「全部課程」清單、沒有「我建立的」與「新增課程」，點任一卡片皆以預覽開啟。 |
| 14 | 以教師甲按「新增課程」，應進入 ET05 的新增課程畫面。 |

## ET02 學員

| 項目 | 說明 |

| 教師甲（主要操作者） | 具教師角色，下列課程甲、乙、丙、丁皆由此帳號建立；本作業全部項目以此帳號操作 |
| 教師乙 | 另一位具教師角色者，自行建立並發布一門課程，用於驗證他人的課程不出現在教師甲的下拉中（第 1 項） |

| 學員 E | 已加入課程甲但**尚未開始任何學習**；用於驗證平均成績「—」與「未達核可資格」（第 3、29 項） |
| 學員 F | 於課程甲「測驗一」作答且**全部答錯得 0 分**；用於驗證平均成績顯示 0 而非「—」（第 3 項） |
| 學員 G | 於課程甲「測驗一」**已作答 2 次（次數用盡）、兩次分數不同且皆未及格**，「測驗二」未作答；用於平均成績只計已作答測驗並取最高分（第 4 項）與重置重考次數（第 15、20、21 項）。沒有用盡次數的學員重置鈕不會亮。第 4 項請在第 20 項之前做 |
| 學員 H | 於課程甲「測驗一」只作答 1 次且未及格（尚有 1 次）、「測驗二」未作答；用於驗證重置鈕停用與「尚未作答」（第 14、19 項） |
| 學員 K | 於課程甲「測驗一」**已及格**；用於驗證已及格者重置鈕停用（第 19 項），及「儲存並要求重測」後重測未及格的情境（第 22 項：學員 K 須於要求重測後再作答 2 次皆不及格） |
| 學員 I | 已加入課程甲，用於移除與重新邀請（第 10～12 項）；須知道課程甲的邀請碼 |
| 學員 J | 已加入課程甲，**於測試當下開始作答某份測驗但先不要交卷**；用於移除作答中學員（第 13 項）。請在第 13 項開始前讓學員 J 開始作答 |
| 兩個瀏覽器分頁 | 以教師甲同時開啟本頁並選定課程甲，用於驗證核可不被覆寫（第 37 項） |

### 測試項目清單

| 項次 | 測試內容 |
|---|---|
| 1 | 以教師甲進入「學員學習表現」，「課程」下拉應只列出教師甲建立的已發布與已關閉課程，不含課程丁（草稿）與教師乙的課程。 |
| 2 | 選擇課程丙（已關閉），應顯示唯讀提示；三區塊照常顯示，「移除」「重置重考次數」皆呈灰色，「匯出 CSV」仍可匯出。 |
| 3 | 選擇課程甲，學員 E 應為「未開始」、進度 0%、平均成績「—」；學員 F 平均成績應顯示「0」而非「—」。 |
| 4 | 學員 G 只作答過「測驗一」（兩次），其平均成績應等於「測驗一」兩次中的較高分，未作答的「測驗二」不列入計算。 |
| 5 | 學員於 ET06 完成課程甲的一個教材項目後，回本頁重新整理，該學員的學習進度應隨即增加。 |
| 6 | 於 ET05 對課程甲新增一份教材並儲存後回本頁，原已完課學員應顯示「進行中」，學習進度之分母隨之增加。 |
| 7 | 按「已加入學員」區塊的「匯出 CSV」，應顯示「CSV 已匯出」並下載檔案；檔案應含全班學員（不受畫面分頁限制），最後一欄為核可狀態且文字與畫面相同。 |
| 8 | 對課程乙按「匯出 CSV」，檔案的核可狀態欄應全部為「—」。 |
| 9 | 完成第 7 項後，以管理者至 DP05 操作記錄查詢，應查得教師甲該次匯出的紀錄與筆數。 |
| 10 | 對學員 I 按「移除」，確認視窗應顯示「確定移除 …？學習歷史完整保留。」；按「確定」後顯示「已移除學員」，學員 I 自三區塊消失，問卷的未填人數同步減少。 |
| 11 | 承上，以學員 I 登入，「我的課程」應不再顯示課程甲；於「加入新課程」輸入課程甲的邀請碼應被擋下並提示已被移除。 |
| 12 | 承上，於 ET05 以 Email 邀請重新邀請學員 I，學員 I 應重新出現在本頁，加入日期為當天，原學習進度與成績接續保留。 |
| 13 | 學員 J 作答中時對其按「移除」，確認視窗應以橘色警告顯示作答中訊息；確定後學員 J 仍可將該次作答交卷並取得分數。 |
| 14 | 「作答明細」區塊應只列出交過卷的學員（學員 E 不在其中）；展開學員 H，課程甲的每份測驗皆列出，未作答的測驗顯示「尚未作答」。 |
| 15 | 展開學員 G 的「測驗一」，兩次作答應各列一行，點選第 1 次（非最近一次）應可開啟該次的逐題明細。 |
| 16 | 於逐題明細中，學員選錯的選項應以紅色標示、漏選的正確答案應註明「（正確答案，未選）」，各題顯示得分與配分。 |
| 17 | 記下某次作答的逐題明細後，於 ET05 修改該題的題幹或正確答案並儲存，再開啟同一次作答的明細，內容與分數應維持作答當時的樣子。 |
| 18 | 學員開始作答但尚未交卷時，該次作答應不出現在作答明細的歷次清單中，「已用 X / Y 次」亦不增加；交卷後重新整理即出現。 |
| 19 | 學員 H「測驗一」的「重置重考次數」應呈灰色，滑鼠移上應顯示尚有幾次可作答；學員 K（已及格）的該按鈕亦呈灰色。 |
| 20 | 對學員 G 的「測驗一」按「重置重考次數」並確定，應顯示「已重置重考次數」，已用次數變為 0，原有兩次作答紀錄仍列出且可點開。 |
| 21 | 承上，以學員 G 登入應可再作答「測驗一」共 2 次；其他測驗的已用次數不受影響。 |
| 22 | 於 ET05 修改「測驗一」並選「儲存並要求重測」，學員 K 重測兩次皆未及格後，本頁學員 K 的「已及格」標示應消失、「重置重考次數」可按。 |
| 23 | 課程甲「問卷結果」區塊之已填與未填人數合計，應等於目前「已加入學員」的人數。 |
| 24 | 選擇課程乙（無課後問卷），應不顯示「問卷結果」區塊。 |
| 25 | 於「統計」檢視，單選題應列出各選項的人數與百分比，問答題只顯示已答人數、不顯示文字內容。 |
| 26 | 切換至「明細」，應逐位學員具名列出各題答案，問答題顯示完整文字。 |
| 27 | 停留在「統計」檢視時按問卷的「匯出 CSV」，下載的檔案應為逐學員明細，含姓名、填答時間與問答題全文。 |
| 28 | 選擇課程乙（未開啟線下核可），清單應無「核可狀態」「核可」欄、勾選框與批次按鈕。 |
| 29 | 選擇課程甲，未完課的學員 E 核可狀態應為「未達核可資格」、無核可按鈕且勾選框呈灰色；已完課的學員 A 應為「待核可」並有「通過」「不通過」。 |
| 30 | 對學員 A 按「通過」並確定，應顯示「已完成核可」，狀態轉為「已通過」並顯示核可人與時間；學員 A 應收到核可通過通知信。 |
| 31 | 對學員 B 按「不通過」，填「備註（選填）」後確定，狀態應轉為「未通過」並顯示該備註；學員 B 應未收到任何通知信。 |
| 32 | 已通過與未通過的學員列，「核可」欄應只有「撤銷」，且勾選框呈灰色（不提供直接改判）。 |
| 33 | 對學員 A 按「撤銷」，撤銷原因留空按「確定」應於欄位提示「請填寫撤銷原因」且未送出；填寫原因後確定，應顯示「已撤銷核可」、狀態回到「待核可」，且學員 A 未收到信。 |
| 34 | 承上，對學員 A 重新按「通過」並確定，狀態應轉為「已通過」，學員 A 再收到一封核可通過通知信。 |
| 35 | 勾選學員 C、D 後按「批次核可通過」，確認視窗應顯示所選人數為 2；確定後兩人皆轉為「已通過」，且各收到一封通知信。 |
| 36 | 學員 A 已通過後，於 ET05 對課程甲新增一份教材，本頁學員 A 應顯示「未達核可資格」；學員 A 補完該教材後應自動回到「已通過」，不需重新核可。 |
| 37 | 於兩個分頁選定課程甲，分頁一將某位待核可學員核可為「通過」後，分頁二不重新整理即對同一學員按「不通過」，應顯示「無法核可：已有核可紀錄」，該學員結果仍為「已通過」（未擋下會靜默改判且無撤銷原因可查）。 |
| 38 | 於 ET05 關閉課程甲的「本課程需線下核可」後回本頁，核可欄與按鈕應隱藏；重新開啟後再回本頁，既有核可結果應維持原樣。 |

## ET03 我的課程

### 測試前準備

| 項目 | 說明 |
|---|---|
| 學員甲（主要操作者） | 具學員角色，本作業絕大多數項目以此帳號進行。須已加入下列課程甲至課程己，統計五項才都有數字可驗（第 3 至 11 項）；另須**尚未加入課程庚**（第 18 項） |
| 學員乙 | 具學員角色、**尚未加入任何課程**、未設定受訓對象，用於驗證主頁「我的學習概況」不顯示與以邀請碼加入（第 1、12 至 17、19 項） |
| 學員丙 | 具學員角色，**曾加入課程戊後被教師於 ET02 移除**，用於驗證被移除後清單與統計的變化及無法自行重新加入（第 2、20 項） |
| 教師 | 具教師角色，為下列課程之建立者；用於提供邀請碼與邀請連結、新增教材（第 9 項）、關閉與再開課（第 10、19 項）及移除學員丙 |
| 課程甲（未開始） | 已發布、閱課期間進行中，學員甲已加入但**尚未完成任何教材或測驗**（第 11 項） |
| 課程乙（進行中） | 已發布、閱課期間進行中，至少 2 項教材或測驗，學員甲**已完成其中部分**（用於驗證完成比例，第 7 項） |
| 課程丙（已完成） | 已發布、閱課期間進行中、設有課後問卷，學員甲已完成全部教材與測驗但**未填寫課後問卷**（問卷不影響已完成，第 8 項；新增教材後回退為進行中，第 9 項） |
| 課程丁（尚未開放） | 已發布、**課程起始時間設在測試當天稍後**（例如 1 小時後），學員甲已加入；起始時間設近一些，才能當天驗證到點後自動變為可點擊（第 4、5 項） |
