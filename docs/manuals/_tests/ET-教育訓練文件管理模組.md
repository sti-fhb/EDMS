# 教育訓練文件管理模組

## ET05 課程建立與編輯

### 測試前準備

| 項目 | 說明 |
|---|---|
| 教師甲（主要操作者） | 具教師角色，本作業絕大多數項目以此帳號進行 |
| 教師乙 | 另一位具教師角色者，用於驗證他人的課程以學員視角預覽（第 4 項） |
| 學員甲 | 具學員角色，且**本人的受訓對象與受測課程的某一組相符**——不相符就驗不到發布時的自動加入（第 54 項） |
| 學員乙 | 具學員角色但**未設定任何受訓對象**，用於驗證 Email 邀請與邀請碼加入（第 60、65 項） |
| 管理者 | 用於停用單位或職位（第 14 項）、停用帳號（第 62 項）與建立帳號 |
| 受訓對象選項 | DP03 中教育訓練的單位與職位各至少 2 項啟用中，其中一組已於 DP02 指派給學員甲；另備一個**已停用**的單位（停用需管理者操作） |
| 沒有相符學員的組合 | 一組沒有任何學員相符的單位與職位，用於驗證「發布後無人符合」的警告（第 56 項） |
| 訓練教材文件 | 文件管理「訓練教材」分類下至少 2 份已發布文件，其中 1 份會在測試中被廢止（第 30 項）；廢止後該份即不可復原，請確認可用 |
| 影片檔 | mp4 或 webm 一支（建議 10 MB 以內，上傳較快）；另備一支**同檔名**的影片（第 27 項） |
| 已有學員通過的測驗 | 一門已發布課程中，某份測驗已有至少 1 位學員通過（第 39、40 項） |
| 已有學員填答之問卷 | 一門已發布課程，其課後問卷**已有學員完成填寫**——題目凍結（第 46 項）只有在有人填過之後才驗得到 |
| 已完課之學員 | 一門已發布課程中至少 1 位學員已完課，用於驗證新增教材後完課狀態回退（第 58 項）；沒有完課者這項驗不到 |
| 作答中的測驗 | 學員於受測課程的某份測驗**已開始作答但尚未交卷**，用於驗證關閉課程當下該次作答仍可完成（第 69 項）；關閉課程前請先讓學員開始作答 |
| 兩個裝置或瀏覽器分頁 | 同時開啟同一門課程的編輯頁，用於驗證版本衝突（第 78 項） |

### 測試項目清單

| 項次 | 測試內容 |
|---|---|
| 1 | 開啟一門草稿課程，標題列右上應只有「預覽課程」，底部動作列應有「刪除草稿」「取消」「儲存草稿」「儲存並發布」。 |
| 2 | 開啟一門已發布課程，底部動作列只剩「取消」「儲存」，標題列右上出現「預覽課程」「邀請學員」「關閉課程」。 |
| 3 | 於草稿課程按「預覽課程」，應以學員視角開啟，全部章節皆可點選、測驗僅能檢視題目無法作答，且不留下任何學習進度。 |
| 4 | 以教師乙於「全部課程」點教師甲的已發布課程，應進入學員視角的預覽頁，而非可編輯的編輯頁。 |
| 5 | 新增課程僅填課程名稱後按「儲存草稿」，應存檔成功並回到課程列表，該課程狀態為草稿。 |
| 6 | 草稿課程的受訓對象與起訖時間全部留空，仍應可按「儲存草稿」成功存檔。 |
| 7 | 受訓對象有一列只選了單位、未選職位就按「儲存草稿」，應擋下並提示補選或刪除該列；兩列選了相同組合時亦應擋下。 |
| 8 | 於課程起始時間按日曆鈕選日期與時間，應以 24 小時制呈現（如 2026/10/15 14:00），按「確認」後帶入欄位。 |
| 9 | 已發布課程按「儲存」後雖顯示「草稿已儲存」，回到列表該課程狀態應仍為已發布、未被退回草稿。 |
| 10 | 開啟一門已開課的課程，原起始時間不變直接儲存應成功；將起始時間再往前調整則應擋下。 |
| 11 | 開啟一門起始時間設在未來的已發布課程，以受訓對象相符的學員登入，「我的課程」應**看得到**此課程，卡片標「尚未開放」且不可點擊、標示開放時點；待起始時間到達後該卡片自動變為可點擊。 |
| 12 | 將已發布課程的訖止時間清空後儲存，系統應擋下並提示改用關閉課程（未擋下該課程將永不到期關閉）。 |
| 13 | 將一門已發布課程的訖止時間改為已過去的時點，學員應即無法再進入學習；待每日排程執行後（或請 IT 手動觸發），課程狀態應自動轉為「已關閉」。 |
| 14 | 已發布課程的既有受訓對象應鎖定（兩欄停用、無刪除鈕），只能新增新的組別；新增時選用已被管理者停用的單位應擋下。 |
| 15 | 已發布課程新增一組受訓對象並儲存，該組相符且尚未加入的學員應被補加入並各收到一封通知信，已在課程中者不重複收信。 |
| 16 | 「本課程需線下核可」於草稿、已發布、已關閉三種狀態皆應可調整，且調整後 ET02 的完課率不受影響。 |
| 17 | 於草稿課程按「刪除草稿」並「確認刪除」，應顯示「草稿已刪除」並回到課程列表，該課程不再出現。 |
| 18 | 按「新增章節」填名稱後按「儲存並繼續新增」，視窗應保留並可接著填下一個章節。 |
| 19 | 新增課程尚未儲存時新增兩個章節後直接離開，課程與章節皆不應保留；改為按「儲存草稿」則兩個章節應一併存入。 |
| 20 | 於章節列上修改章節名稱後將游標移出欄位，名稱應自動儲存，重新整理後仍為新名稱。 |
| 21 | 拖曳章節左側手把調整順序後重新整理，調整後的順序應保留。 |
| 22 | 刪除一個已有學員學習紀錄的章節並確認，該章節的學習紀錄與測驗成績應一併移除、不再計入完課率，後續章節順序自動往前遞補。 |
| 23 | 於新增課程畫面（課程尚未儲存）按「新增項目 → 教材」，填名稱按「建立」，應顯示「已自動儲存草稿」、轉入該課程編輯頁並開啟教材視窗；重新整理後該課程仍在。 |
| 24 | 於章節內按「新增項目 → 教材」，於名稱視窗填名稱按「建立」，教材視窗的「項目標題」應已帶入該名稱；填說明文字後按「儲存」，該章節下應出現此教材。 |
| 25 | 新建立的教材在第一次按「儲存」前就按「取消」，該教材不應留在章節中。 |
| 26 | 於教材選檔上傳一支影片後直接按「取消」關閉視窗，重新開啟該教材，影片應仍在（影片為選檔即上傳）。 |
| 27 | 教材上傳區應顯示支援的影片格式與單檔大小上限；對已有影片的教材再上傳一支同檔名的影片，應擋下並提示先移除原有影片或改用其他檔名。 |
| 28 | 於教材引用一份「訓練教材」分類的已發布文件並儲存，學員於該章節應可開啟此文件。 |
| 29 | 將教材已引用的文件於文件管理端發布新版本，學員下次開啟該章節應取得新版內容，教師端不需回頭更新引用。 |
| 30 | 將已被引用的文件於文件管理端廢止，回到該教材應顯示「此文件已廢止」，且該課程按「儲存並發布」會被擋下。 |
| 31 | 移除已廢止文件的引用並儲存後再按「儲存並發布」，該項檢核應通過。 |
| 32 | 於章節內按「新增項目 → 測驗」並建立，於「測驗設定」填及格分數與重考次數上限後按「儲存」，該章節下應出現此測驗。 |
| 33 | 「作答時間限制」留空儲存，學員作答該測驗時應不限時；改填入數字後，學員端應為該分鐘數的限時作答。 |
| 34 | 「重考次數上限」填 0 儲存，學員該測驗作答一次後應不可重考。 |
| 35 | 於「題庫管理」新增一題並按該題的「儲存題目」後，不按底部「儲存」直接關閉視窗，重新開啟該題應仍在。 |
| 36 | 展開一題編輯但未按「儲存題目」即關閉視窗，該次編輯的內容應消失。 |
| 37 | 刪除一題已有學員作答的題目並確認，該題不應再出現於之後的作答；已作答學員的紀錄與成績應完整保留、仍可回看。 |
| 38 | 已發布課程的測驗只剩 1 題時刪除該題，應擋下並提示不可刪除最後一題。 |
| 39 | 對已有學員通過的測驗新增一題並儲存，應跳出「是否要求已通過的學員重新測驗？」並顯示通過人數；選「儲存並要求重測」後，該學員的測驗應回到未完成並收到通知信。 |
| 40 | 承上，改選「僅儲存，不要求重測」，已通過的學員應維持通過；選「取消」則不儲存。 |
| 41 | 於「課後問卷」區按「新增問卷」，於「新增課後問卷」視窗填名稱按「建立」，同一視窗應隨即切換為題目編輯。 |
| 42 | 對一門已有課後問卷的課程再按「新增問卷」，應擋下並提示一門課程僅可建立 1 份（未擋下會出現兩份問卷，學員不知該填哪份）。 |
| 43 | 問卷尚無題目時，視窗內應出現「套用模板」，套用後帶入一組題目且可自由增刪修改。 |
| 44 | 問卷已有題目後重新開啟視窗，應不再提供「套用模板」。 |
| 45 | 將一題由單選改為問答，原本已填的選項應被清空。 |
| 46 | 已有學員填答的問卷，卡片上的「編輯」按鈕應呈灰色不可按，滑鼠移上去應說明已有學員填答、此時僅可停用問卷。 |
| 47 | 將已有學員填答的問卷停用，學員端應不再顯示填寫入口，已填寫的內容仍保留。 |
| 48 | 草稿課程的問卷應只提供刪除；已發布課程的問卷應只提供停用、不提供刪除。 |
| 49 | 一門沒有任何章節的課程按「儲存並發布」，視窗應列出缺章節並說明該去哪裡補，視窗只有「關閉」可按。 |
| 50 | 有章節但該章節沒有任何教材或測驗時按「儲存並發布」，視窗應列出缺漏；關閉視窗後該章節應以紅框標示。 |
| 51 | 未設定任何受訓對象、起訖時間未填齊時按「儲存並發布」，視窗應一併列出；關閉視窗後該兩欄以紅框標示，補填後紅框隨即消失。 |
| 52 | 某份測驗各題配分總和不等於 100 時按「儲存並發布」，視窗應列出該測驗配分不符，關閉後該測驗以紅框標示。 |
| 53 | 草稿課程已建立問卷但問卷沒有任何題目時按「儲存並發布」，應一併擋下；將該問卷刪除後應即可發布。 |
| 54 | 全部檢核通過後按「確認發布」，課程狀態應轉為「已發布」，並顯示依受訓對象帶入的學員人數與一組 8 碼邀請碼，該批學員各收到一封通知信；課程建立者本人不應被加入。 |
| 55 | 發布後重新整理編輯頁，上方顯示的邀請碼應為同一組，且畫面不提供重新產生。 |
| 56 | 發布一門受訓對象沒有任何相符學員的課程，應顯示課程已發布但無學員符合受訓對象的警告，並提示可改用邀請碼。 |
| 57 | 已發布課程新增一個章節並儲存，所有已加入的學員應收到通知信。 |
| 58 | 已發布課程新增一份教材並儲存，已完課學員的完課狀態應回退為「進行中」，其已填寫的課後問卷不需重填。 |
| 59 | 「邀請學員」按鈕應僅於課程已發布時顯示於標題列右上，草稿與已關閉狀態皆不顯示。 |
| 60 | 於「Email 邀請（補件）」輸入一組全為既有帳號的名單，按「下一步」顯示預覽後按「確認寄出」，各收件人應收到邀請信，且**立即出現在 ET02 學員學習表現的清單中**（不需要他們做任何事）。 |
| 61 | 名單中含尚未建立帳號的 Email 時，應整批不寄出任何一封，並列出是哪幾筆查無帳號。 |
| 62 | 名單中含已停用的帳號時，應整批不寄出任何一封，並列出是哪幾個帳號已停用。 |
| 63 | 邀請信預覽的主旨與內文應不可編輯，且不含任何一位收件人的稱謂（以佔位字樣呈現）；信中連結應為課程學習頁。 |
| 64 | 邀請錯人時，於 ET02 學員學習表現對該員按「移除」應可將其移出課程（已無「撤回邀請」）。 |
| 65 | 於「邀請碼」分頁取得邀請碼，學員於「我的課程 → 加入新課程」輸入該碼應可加入本課程。 |
| 66 | 按標題列右上「關閉課程」並於視窗按「確認關閉」，課程狀態應立即轉為「已關閉」。 |
| 67 | 課程關閉後，學員於「我的課程」仍應看得到該課程並標示已關閉，且可唯讀回看已學過的內容與成績。 |
| 68 | 課程關閉後，學員應不能累積新進度、不能開始新的測驗作答、不能解鎖新章節、不能填寫課後問卷。 |
| 69 | 於學員作答中關閉課程，該次作答應仍可完成並計分；交卷後不能再開始新的作答。 |
| 70 | 課程關閉期間教師仍應可編輯課程內容並儲存，但「邀請學員」按鈕不顯示，且 ET02 不可重置重考次數。 |
| 71 | 課程關閉期間學員於「加入新課程」輸入該課程的邀請碼，應被擋下。 |
| 72 | 按「再開課」時基本資料的兩個時間欄位應就地清空並標為必填，底部動作列應換成「取消再開課」與「確認再開課」；未填妥不能送出。 |
| 73 | 按「再開課」清空時間後改按「取消再開課」，兩個時間欄位應還原成原本的值，且課程資料未被更動。 |
| 74 | 再開課的新起始時間填在過去的日期應可送出；訖止時間早於起始時間時應擋下並提示。 |
| 75 | 再開課完成後畫面上的起訖時間應立即顯示為剛剛填入的值，不需離開頁面再進來。 |
| 76 | 於關閉期間移除某項必要內容（如刪光教材）後按「確認再開課」，應跳出「再開課」視窗列出缺漏，關閉後缺漏處以紅框標示、畫面仍停在再開課模式；補齊後再按一次即可完成。 |
| 77 | 再開課完成後課程應回到「已發布」，學員的學習進度與成績接續保留、原邀請碼恢復有效。 |
| 78 | 於兩個裝置同時開啟同一門課程的編輯頁，其中一邊儲存後另一邊再儲存，應擋下並提示內容已被其他裝置變更，且該次編輯不覆蓋先前的儲存。 |
