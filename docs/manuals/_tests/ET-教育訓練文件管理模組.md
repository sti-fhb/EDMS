# 教育訓練文件管理模組

## ET02 課程建立與編輯

### 測試前準備

| 項目 | 說明 |
|---|---|
| 教師甲（主要操作者） | 具教師角色，本作業絕大多數項目以此帳號進行 |
| 教師乙 | 另一位具教師角色者，用於驗證非擁有者只能唯讀（第 2 項） |
| 學員甲 | 具學員角色，且**已掛上受測課程所用的受訓單位標籤**——沒掛標籤就驗不到發布時的自動加入（第 46 項） |
| 學員乙 | 具學員角色但**未掛任何標籤**，用於驗證 Email 邀請與邀請碼加入（第 51、55 項） |
| 管理者 | 用於停用標籤（第 11 項）與建立帳號 |
| 受訓單位標籤 | 至少兩個啟用中標籤，其中一個已指派給學員甲；另備一個**已停用**標籤（停用標籤無法由教師自建，需管理者先停用） |
| 未指派給任何人的標籤 | 一個啟用中但沒有任何學員掛上的標籤，用於驗證「發布後無人符合」的警告（第 48 項）——若所有標籤都有人，這項驗不到 |
| 訓練教材文件 | 文件管理「訓練教材」分類下至少 2 份已發布文件，其中 1 份會在測試中被廢止（第 24 項）；廢止後該份即不可復原，請確認可用 |
| 影片檔 | mp4 或 webm 一支（建議 10 MB 以內，上傳較快）；另備一支**同檔名**的影片（第 21 項） |
| 已有學員填答之問卷 | 一門已發布課程，其課後問卷**已有學員完成填寫**——題目凍結（第 37 項）只有在有人填過之後才驗得到 |
| 已完課之學員 | 一門已發布課程中至少 1 位學員已完課，用於驗證新增章節後完課狀態回退（第 49 項）；沒有完課者這項驗不到 |
| 作答中的測驗 | 學員於受測課程的某份測驗**已開始作答但尚未交卷**，用於驗證關閉課程當下該次作答仍可完成（第 59 項）；關閉課程前請先讓學員開始作答 |
| 兩個裝置或瀏覽器分頁 | 同時開啟同一門課程的編輯頁，用於驗證版本衝突（第 65 項） |

### 測試項目清單

| 項次 | 測試內容 |
|---|---|
| 1 | 開啟一門草稿課程，底部動作列應有「取消」「儲存草稿」「儲存並發布」三顆，標題列右上不顯示操作按鈕。 |
| 2 | 以教師乙開啟教師甲建立的課程，畫面上方應顯示由誰建立，所有欄位停用、底部不顯示操作按鈕。 |
| 3 | 開啟一門已發布課程，底部動作列只剩「取消」「儲存」，標題列右上出現「邀請學員」與「關閉課程」。 |
| 4 | 新增課程僅填課程名稱後按「儲存草稿」，應存檔成功並回到課程列表，該課程狀態為草稿。 |
| 5 | 草稿課程的受訓單位標籤與起訖時間全部留空，仍應可按「儲存草稿」成功存檔。 |
| 6 | 已發布課程按「儲存」後雖顯示「草稿已儲存」，回到列表該課程狀態應仍為已發布、未被退回草稿。 |
| 7 | 開啟一門已開課的課程，原起始時間不變直接儲存應成功；將起始時間再往前調整則應擋下。 |
| 8 | 開啟一門起始時間設在未來的已發布課程，以該課程標籤內的學員登入，「我的課程」應**看得到**此課程，卡片標「尚未開放」且不可點擊、標示開放時點；統計卡「已加入課程」應計入它，「未開始」不應計入。待起始時間到達後該卡片自動變為可點擊，不需學員操作。 |
| 9 | 將已發布課程的訖止時間清空後儲存，系統應擋下並提示改用關閉課程（未擋下該課程將永不到期關閉）。 |
| 10 | 將一門已發布課程的訖止時間改為已過去的時點，待每日排程執行後（或請 IT 手動觸發），課程狀態應自動轉為「已關閉」，不需教師操作。 |
| 11 | 已發布課程的既有受訓單位標籤上應無移除鈕，只能新增；改選已被管理者停用的標籤應擋下。 |
| 12 | 已發布課程新增一個受訓單位標籤並儲存，該標籤對應且尚未加入的學員應被補加入並各收到一封通知信，已在課程中者不重複收信。 |
| 13 | 「本課程需線下核可」於草稿、已發布、已關閉三種狀態皆應可調整，且調整後 ET03 的完課率不受影響。 |
| 14 | 按「新增章節」填名稱後按「儲存並繼續新增」，視窗應保留並可接著填下一個章節。 |
| 15 | 於章節列上修改章節名稱後將游標移出欄位，名稱應自動儲存，重新整理後仍為新名稱。 |
| 16 | 拖曳章節左側手把調整順序後重新整理，調整後的順序應保留。 |
| 17 | 刪除一個已有學員學習紀錄的章節並確認，該章節的學習紀錄與測驗成績應一併移除、不再計入完課率，後續章節順序自動往前遞補。 |
| 18 | 於新增課程畫面（課程尚未儲存）按「新增項目」，應顯示「已自動儲存草稿」、轉入該課程編輯頁並開啟項目視窗；重新整理後該課程仍在。 |
| 19 | 於章節內按「新增項目 → 教材」，填項目標題與說明文字後按「儲存」，該章節下應出現此教材。 |
| 20 | 於教材選檔上傳一支影片後直接按「取消」關閉視窗，重新開啟該教材，影片應仍在（影片為選檔即上傳）。 |
| 21 | 對已有影片的教材再上傳一支同檔名的影片，應擋下並提示先移除原有影片或改用其他檔名。 |
| 22 | 於教材引用一份「訓練教材」分類的已發布文件並儲存，學員於該章節應可開啟此文件。 |
| 23 | 將教材已引用的文件於文件管理端發布新版本，學員下次開啟該章節應取得新版內容，教師端不需回頭更新引用。 |
| 24 | 將已被引用的文件於文件管理端廢止，回到該教材應顯示「此文件已廢止」，且該課程按「儲存並發布」會被擋下。 |
| 25 | 逐筆移除已廢止文件的引用後再按「儲存並發布」，該項檢核應通過。 |
| 26 | 於章節內按「新增項目 → 測驗」，填及格分數與重考次數上限後按「儲存」，該章節下應出現此測驗。 |
| 27 | 「作答時間限制」留空儲存，學員作答該測驗時應不限時；改填入數字後，學員端應為該分鐘數的限時作答。 |
| 28 | 「重考次數上限」填 0 儲存，學員該測驗作答一次後應不可重考。 |
| 29 | 於「題庫管理」新增一題並按該題的「儲存題目」後，不按底部「儲存」直接關閉視窗，重新開啟該題應仍在。 |
| 30 | 展開一題編輯但未按「儲存題目」即關閉視窗，該次編輯的內容應消失。 |
| 31 | 刪除一題已有學員作答的題目並確認，該題不應再出現於之後的作答；已作答學員的紀錄與成績應完整保留、仍可回看。 |
| 32 | 於「課後問卷」區按「新增問卷」填名稱後按「建立」，再按「編輯」應可開啟問卷視窗逐題撰寫。 |
| 33 | 對一門已有課後問卷的課程再按「新增問卷」，應擋下並提示一門課程僅可建立 1 份（未擋下會出現兩份問卷，學員不知該填哪份）。 |
| 34 | 問卷尚無題目時，視窗內應出現「套用模板」，套用後帶入一組題目且可自由增刪修改。 |
| 35 | 問卷已有題目後重新開啟視窗，應不再提供「套用模板」。 |
| 36 | 將一題由單選改為問答，原本已填的選項應被清空。 |
| 37 | 已有學員填答的問卷，卡片上的「編輯」按鈕應呈灰色不可按，滑鼠移上去應說明已有學員填答、此時僅可停用問卷。 |
| 38 | 將已有學員填答的問卷停用，學員端應不再顯示填寫入口，已填寫的內容仍保留。 |
| 39 | 草稿課程的問卷應可刪除；已發布課程的問卷應只提供停用、不提供刪除。 |
| 40 | 一門沒有任何章節的課程按「儲存並發布」，檢核視窗應列出缺章節並指出該去哪個區塊補。 |
| 41 | 有章節但章節下沒有任何教材時按「儲存並發布」，檢核視窗應列出缺教材。 |
| 42 | 未掛任何受訓單位標籤時按「儲存並發布」，檢核視窗應列出缺標籤。 |
| 43 | 起訖時間未填齊時按「儲存並發布」，檢核視窗應列出缺時間。 |
| 44 | 某份測驗各題配分總和不等於 100 時按「儲存並發布」，檢核視窗應列出該測驗配分不符。 |
| 45 | 課程已建立問卷但問卷沒有任何題目時按「儲存並發布」，應一併擋下；將該問卷停用後應即可發布。 |
| 46 | 六項檢核全數通過後按「確認發布」，課程狀態應轉為「已發布」，並顯示依標籤帶入的學員人數與一組 8 碼邀請碼，該批學員各收到一封通知信。 |
| 47 | 發布後重新整理編輯頁，上方顯示的邀請碼應為同一組，且畫面不提供重新產生。 |
| 48 | 發布一門所掛標籤未指派給任何人的課程，應顯示課程已發布但無學員符合標籤的警告，並提示可改用邀請碼。 |
| 49 | 已發布課程新增一個章節並儲存，所有已加入的學員應收到通知信，且已完課學員的完課狀態回退為「進行中」，其已填寫的課後問卷不需重填。 |
| 50 | 「邀請學員」按鈕應僅於課程已發布時顯示於標題列右上，草稿與已關閉狀態皆不顯示。 |
| 51 | 於「Email 邀請」輸入一組全為既有帳號的名單，按「下一步」顯示預覽後按「確認寄出」，各收件人應收到邀請信，且**立即出現在「學員」頁的清單中**（不需要他們做任何事）。 |
| 52 | 名單中含尚未建立帳號的 Email 時，應整批不寄出任何一封，並列出是哪幾筆查無帳號。 |
| 53 | 邀請信預覽的主旨與內文應不可編輯，且不含任何一位收件人的稱謂（以佔位字樣呈現）；信中連結應為課程學習頁。 |
| 54 | 邀請錯人時，於「學員」頁對該員按「移除」應可將其移出課程（已無「撤回邀請」）。 |
| 55 | 於「邀請碼」分頁取得邀請碼，學員於「我的課程 → 加入新課程」輸入該碼應可加入本課程。 |
| 56 | 按標題列右上「關閉課程」並於視窗按「確認關閉」，課程狀態應立即轉為「已關閉」。 |
| 57 | 課程關閉後，學員於「我的課程」仍應看得到該課程並標示已關閉，且可唯讀回看已學過的內容與成績。 |
| 58 | 課程關閉後，學員應不能累積新進度、不能開始新的測驗作答、不能解鎖新章節、不能填寫課後問卷。 |
| 59 | 於學員作答中關閉課程，該次作答應仍可完成並計分；交卷後不能再開始新的作答。 |
| 60 | 課程關閉期間教師仍應可編輯課程內容並儲存，但「邀請學員」按鈕不顯示，且 ET03 不可重置重考次數。 |
| 61 | 課程關閉期間學員於「加入新課程」輸入該課程的邀請碼，應被擋下。 |
| 62 | 按「再開課」時視窗的兩個時間欄位應為空、不帶入原本的值，未填妥不能送出。 |
| 63 | 於關閉期間移除某項必要內容（如刪光教材）後按「確認再開課」，應重新跑六項檢核並逐條列出缺漏；補齊後於同一視窗再按一次即可完成。 |
| 64 | 再開課完成後課程應回到「已發布」，學員的學習進度與成績接續保留、原邀請碼恢復有效。 |
| 65 | 於兩個裝置同時開啟同一門課程的編輯頁，其中一邊儲存後另一邊再儲存，應擋下並提示內容已被其他裝置變更，且該次編輯不覆蓋先前的儲存。 |
