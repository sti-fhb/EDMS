# 教育訓練文件管理模組

## ET01 課程列表

### 測試前準備

| 項目 | 說明 |
|---|---|
| 教師甲（主要操作者） | 具教師角色。名下需有草稿、已發布、已關閉課程各至少 1 門，其中一門已發布課程至少有 2 位學員（第 4 項移除一位）。教師甲本人**不可**以學員身分加入自己或教師乙的這些課程（「全部課程」不列出自己已加入的課程） |
| 教師乙 | 另一位具教師角色者。名下需有已發布課程至少 1 門、草稿 1 門、已關閉 1 門（第 2 項）；已發布課程的受訓對象與教師甲的課程不同，第 3 項才看得出篩選效果 |
| 管理者丙 | 具教育訓練管理者角色、**不具教師角色**（第 5 項）；兼具教師角色者驗不到 |

### 測試項目清單

| 項次 | 測試內容 |
|---|---|
| 1 | 以教師甲進入課程列表，「我建立的」應列出教師甲本人的草稿、已發布、已關閉課程，不含其他教師的課程；點其中任一門應進入可編輯的 ET05 編輯頁；按「新增課程」應進入 ET05 的新增課程畫面。 |
| 2 | 切到「全部課程」，應列出教師乙的已發布課程，教師乙的草稿與已關閉課程不出現；點教師乙的課程（卡片標「檢視」）應以學員視角開啟，頁首顯示「預覽模式」並說明預覽不會累積學習進度；點同一清單中教師甲本人的已發布課程，同樣進入預覽頁（頁首說明「您是本課程的建立者」）而非編輯頁。 |
| 3 | 於「全部課程」以「關鍵字」「建立者」「單位」「職位」任一條件或組合查詢，清單應只列出符合條件的課程。 |
| 4 | 於 ET02 學員學習表現選擇教師甲的該課程，對其中一位學員按「移除」並確定後回到課程列表，該課程卡片的學員人數應減少一位。 |
| 5 | 以管理者丙登入進入課程列表，應只有「全部課程」清單，點任一卡片皆以預覽開啟。 |

## ET02 學員

### 測試前準備

| 項目 | 說明 |
|---|---|
| 登入帳號 | 教師帳號兩組（教師甲、教師乙）、學員帳號三組（學員甲、乙、丙，皆需能收信）、教育訓練管理者帳號一組 |
| 課程甲（主要受測課程） | 教師甲已發布、閱課期間進行中、**已開啟「本課程需線下核可」**、設有課後問卷（至少 1 題單選與 1 題問答）；章節內依序為至少 1 份教材、「測驗一」、「測驗二」，「測驗一」至少 3 題、配分不同（例如 30／30／40 分）、及格分數 60，重考次數上限設為 1（共可作答 2 次）。學員甲、乙、丙請由教師甲於 ET05「邀請學員」→「Email 邀請（補件）」加入，**勿由學員自行輸入邀請碼**（加入後會直接進入課程並自動開啟第一份教材，純文字教材一開啟即算完成）；加入後在第 4 項之前不要以學員身分進入課程甲。本作業最後會關閉此課程（第 22 項） |
| 課程乙 | 教師甲已發布、**未開啟**線下核可、**未建立**課後問卷、至少 1 位學員之課程（第 3 項） |
| 課程丙 | 教師甲已關閉之課程一門（第 1 項） |
| 課程丁 | 教師甲的草稿課程（第 1 項） |
| 教師乙之課程 | 教師乙已發布之課程一門（第 1 項） |

### 測試項目清單

| 項次 | 測試內容 |
|---|---|
| 1 | 以教師甲進入「學員學習表現」，「課程」下拉應只列出教師甲建立的已發布與已關閉課程，不含教師甲的草稿課程與教師乙的課程。 |
| 2 | 選擇教師甲一門已發布、已開啟「本課程需線下核可」、設有課後問卷，並含「測驗一」（可作答 2 次）與「測驗二」的課程（以下稱受測課程），學員甲、乙、丙已加入但尚未開始學習時，三人皆應為「未開始」、進度 0%、平均成績「—」。 |
| 3 | 選擇教師甲另一門未開啟線下核可、未建立課後問卷的已發布課程，清單應無「核可狀態」「核可」欄、勾選框與批次按鈕，且不顯示「問卷結果」區塊；按「匯出 CSV」，檔案的核可狀態欄應全部為「—」。 |
| 4 | 學員甲於 ET06 完成受測課程的第一份教材後，重新進入本作業選擇受測課程，學員甲的學習進度應增加。 |
| 5 | 學員甲作答「測驗一」並全部答錯交卷後，學員甲的平均成績應顯示「0.00」而非「—」；於「作答明細」按學員甲展開，其「測驗一」的「重置重考次數」應呈灰色，滑鼠移上應顯示尚有幾次可作答。 |
| 6 | 「作答明細」區塊應只列出學員甲（尚未交卷的學員乙、丙不在其中），學員甲的每份測驗皆列出，未作答的「測驗二」顯示「尚未作答」；點該次作答的「查看逐題明細」，選錯的選項應以紅色標示、漏選的正確答案應註明「（正確答案，未選）」，各題顯示得分與配分。 |
| 7 | 記下學員甲該次作答的逐題明細後，於 ET05 開啟「測驗一」修改該題的題幹或正確答案並按「儲存題目」，於「是否要求學員重新測驗？」視窗選「僅儲存，不要求重測」，關閉測驗視窗後按「更新」並於確認視窗按「確認更新」；回本頁再開啟同一次作答的明細，內容與分數應維持作答當時的樣子。 |
| 8 | 學員甲再作答「測驗一」一次、未及格且分數與第一次不同後，平均成績應等於「測驗一」兩次中的較高分，未作答的「測驗二」不列入計算；展開學員甲的「測驗一」，兩次作答應各列一行，點第 1 次應可開啟該次的逐題明細。 |
| 9 | 學員甲「測驗一」兩次皆未及格（次數用盡）後，對其「測驗一」按「重置重考次數」並確定，應顯示「已重置重考次數」，已用次數變為 0，原有兩次作答紀錄仍列出且可點開；以學員甲登入進入「測驗一」，「剩餘可作答」應顯示 2 次（此時先不要作答）。 |
| 10 | 學員甲於重置後再作答「測驗一」一次並及格後，作答明細應於該次之前出現一列「重考次數已重置」與日期，先前兩次照常顯示、不標「前一輪」，平均成績取三次中的最高分；其「重置重考次數」應呈灰色。 |
| 11 | 學員甲、乙學完受測課程全部內容（含「測驗二」），且學員甲填寫課後問卷（問答題填文字）後，按「已加入學員」區塊的「匯出 CSV」，應顯示「CSV 已匯出」並下載檔案；檔案應含全班學員，最後一欄為核可狀態且文字與畫面相同。 |
| 12 | 「問卷結果」區塊之已填與未填人數合計應等於「已加入學員」的人數；於「統計」檢視，單選題應列出各選項的人數與百分比，問答題只顯示已答人數；切換至「明細」，應逐位學員具名列出各題答案；於「統計」檢視按問卷的「匯出 CSV」，下載的檔案應為逐學員明細，含姓名、填答時間與問答題全文。 |
| 13 | 尚未開始學習的學員丙核可狀態應為「未達核可資格」、無核可按鈕且勾選框呈灰色；已完課的學員甲應為「待核可」並有「通過」「不通過」。 |
| 14 | 對學員甲按「通過」並確定，應顯示「已完成核可」，狀態轉為「已通過」並顯示核可人與時間；學員甲應收到核可通過通知信。 |
| 15 | 對學員乙按「不通過」，填「備註（選填）」後確定，狀態應轉為「未通過」並顯示該備註，學員乙應未收到核可相關通知信；此時學員甲、乙兩列的「核可」欄應只有「撤銷」，且勾選框呈灰色（不提供直接改判）。 |
| 16 | 對學員甲按「撤銷」，撤銷原因留空按「確定」應提示「請填寫撤銷原因」且未送出；填寫原因後確定，應顯示「已撤銷核可」、狀態回到「待核可」，學員甲未收到核可相關通知信；再對學員甲按「通過」並確定，狀態轉為「已通過」，學員甲再收到一封核可通過通知信。 |
| 17 | 將學員甲、學員乙的核可撤銷回到「待核可」後，勾選兩人按「批次核可通過」，確認視窗應顯示所選人數為 2；確定後兩人皆轉為「已通過」，且各收到一封通知信。 |
| 18 | 於 ET05 對受測課程新增一份教材並按「更新」後回本頁，學員甲、乙應顯示「進行中」、學習進度隨項目總數增加而下降，學員甲核可狀態為「未達核可資格」；學員甲補完該教材後，離開本作業再重新進入並選擇受測課程，學員甲應自動回到「已完成」「已通過」，不需重新核可。 |
| 19 | 於 ET05 關閉受測課程的「本課程需線下核可」並按「更新」後回本頁，核可欄與按鈕應隱藏；重新開啟並按「更新」後再回本頁，學員甲應仍為「已通過」並顯示原核可人與時間（學員乙尚未補完第 18 項新增的教材，顯示「未達核可資格」屬正常）。 |
| 20 | 學員丙學完「測驗一」之前的教材並作答「測驗一」至及格、「測驗二」未作答時，於 ET05 修改「測驗一」某題的題幹並選「儲存並要求重測」後按「更新」（學員甲、乙亦會收到重測通知信，屬正常），學員丙重測兩次皆未及格且兩次分數不同後，本頁學員丙的「已及格」標示應消失、「重置重考次數」可按；作答明細於重測後第一次作答之前出現一列「教師要求重測（測驗內容已更新）」與日期，重測前的作答以灰色顯示並標「前一輪」且仍可開啟，平均成績只取重測後兩次中的較高分（不含重測前的及格分數）。 |
| 21 | 對尚未填寫課後問卷的學員丙按「移除」，確認視窗應顯示「確定移除 …？學習歷史完整保留。」；確定後學員丙自三區塊消失、問卷未填人數減少；以學員丙登入，「我的課程」不再顯示受測課程，輸入受測課程的邀請碼應被擋下並提示已被移除；於 ET05 以 Email 邀請重新邀請學員丙後，學員丙重新出現在本頁，加入時間更新為重新邀請的時點，原學習進度與成績接續保留。 |
| 22 | 於 ET05 關閉受測課程後回本頁選擇受測課程，應顯示唯讀提示；三區塊照常顯示，「移除」「重置重考次數」皆呈灰色，「匯出 CSV」仍可匯出。 |
| 23 | 以管理者於 DP05 操作記錄查詢，以操作者「教師甲」、功能「ET-個資匯出」篩選，應查得第 11 項匯出的紀錄；按「明細」，事件描述應為「匯出學員清單 CSV（N 筆）」，N 等於當時的學員人數。 |

## ET03 我的課程

### 測試前準備

| 項目 | 說明 |
|---|---|
| 學員甲（主要操作者） | 具學員角色，已加入下列課程甲至課程戊，**尚未加入可加入課程** |
| 學員乙 | 具學員角色、未設定受訓對象，尚未加入下列可加入課程、辛、戊（第 8～10、12 項） |
| 教師 | 具教師角色，為下列課程之建立者；用於提供邀請碼與邀請連結、新增教材（第 5 項）、關閉與再開課（第 6、12 項） |
| 課程甲（未開始） | 已發布、閱課期間進行中，學員甲已加入但**尚未完成任何教材或測驗** |
| 課程乙（進行中） | 已發布、閱課期間進行中，至少 2 項教材或測驗，學員甲**已完成其中部分** |
| 課程丙（已完成） | 已發布、閱課期間進行中、設有課後問卷，學員甲已完成全部教材與測驗但**未填寫課後問卷** |
| 課程丁（尚未開放） | 已發布、**課程起始時間設在測試當天稍後**（例如 1 小時後），學員甲已加入 |
| 課程戊（已關閉） | 已發布、**含至少 1 份教材與 1 份測驗**，學員甲已加入並完成其中部分教材、測驗尚未作答，之後由教師按「關閉課程」關閉 |
| 可加入課程（可加入） | 已發布、閱課期間進行中，學員甲與學員乙皆**尚未加入**；記下其 8 碼邀請碼與邀請連結 |
| 課程辛（尚未開放、可加入） | 已發布、課程起始時間在未來，學員乙尚未加入；記下其邀請碼 |

### 測試項目清單

| 項次 | 測試內容 |
|---|---|
| 1 | 以學員甲登入，於主頁「我的學習概況」按「前往我的課程」應進入本頁。 |
| 2 | 以學員甲進入「我的課程」，「已加入課程」應等於進行中、未開始、尚未開放、已完成四項之和且與實際卡片數一致；主頁「我的學習概況」的四個數字應與本頁逐項相同（主頁的「未開放」即本頁的「尚未開放」）。 |
| 3 | 起始時間設在稍後（尚未開放）的已加入課程，卡片應標「尚未開放」、顯示「將於（開放時點）開放學習」且不可點擊，並計入「尚未開放」；待起始時間到達後重新進入本頁，該卡片應改為可點擊，改計入「未開始」。 |
| 4 | 已完成部分項目的課程，卡片的「完成 N%」應等於已完成的教材與測驗數 ÷ 全部教材與測驗數；於該課程再完成一項後回到本頁，比例應隨之增加。 |
| 5 | 已完成全部教材與測驗但未填課後問卷的課程，卡片應標「已完成」並計入「已完成」；教師於該課程新增一份教材並按「更新」後，該課程應改標「進行中」，統計同步由已完成移至進行中。 |
| 6 | 已由教師關閉、含測驗的已加入課程（以下稱已關閉課程），卡片應標「已關閉」，點入後應顯示「此課程目前關閉中，僅可回看已學內容」，可開啟各教材但課程進度不增加；開啟測驗應顯示「此課程已關閉，無法再開新作答」且「開始作答」呈灰色。 |
| 7 | 點一門尚未開始的已加入課程卡片，應進入該課程的 ET06 課程學習。 |
| 8 | 取得一門學員甲、乙皆未加入的已發布課程（以下稱可加入課程）的邀請碼，以學員乙按「加入新課程」輸入該邀請碼按「查詢」，應顯示課程名稱、教師與章節數；此時按「上一步」再按「取消」關閉視窗，可加入課程不應出現在清單上。再次查詢後按「確認加入」，應顯示「已加入課程」並進入可加入課程的 ET06；回到本頁可加入課程列於清單，「已加入課程」加 1（進入 ET06 時已開啟第一份教材，可加入課程計入「進行中」）。 |
| 9 | 以學員乙輸入一門起始時間在未來、尚未加入之課程的邀請碼查詢，應提示開放時點；按「確認加入」後應顯示「已加入，課程開放後即可開始學習」並留在本頁，該課程的卡片標「尚未開放」。 |
| 10 | 學員乙再次輸入已加入之可加入課程的邀請碼按「查詢」，應直接進入可加入課程的 ET06，且「已加入課程」數不增加。 |
| 11 | 以學員甲開啟可加入課程的邀請連結並登入，應進入本頁並自動開啟「加入新課程」視窗並填好邀請碼，在按「查詢」與「確認加入」前不應已加入。 |
| 12 | 以學員乙輸入已關閉課程的邀請碼，應擋下並顯示「此課程目前關閉中」；教師於 ET05 開啟該課程按「更新並重開課」後，學員乙以同一組邀請碼應可加入。 |

## ET04 核可查詢

### 測試前準備

| 項目 | 說明 |
|---|---|
| 教師甲 | 具教師角色，為「課程 A」的開設者；於 ET02 執行撤銷與重新核可（第 9、10 項） |
| 教師乙 | 另一位具教師角色者，**未開設課程 A**、為課程 B 的開設者（第 2、7 項） |
| 管理者 | 具教育訓練管理者角色（第 2、7、8 項） |
